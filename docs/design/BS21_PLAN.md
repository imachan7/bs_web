## 2. 確認したもの（2026-11-06 ユーザー確認）

| # | カード・節 | 決まったこと |
| :-- | :-- | :-- |
| 0 | CP13-01 ミニーズ特攻隊 | **入れる**（93枚にする）。「デッキに何枚でも入れることができる」はデッキの同名枚数の検査を変える |
| 1 | 004「この効果はターンに1回しか使えない」 | カード名ごと（プレイヤーに掛かる制限。一般則として SEMANTICS_AUDIT §3 に書いた） |
| 2 | 073 連鎖[紫]「コスト7のスピリットカード1枚を召喚できる」 | 文言どおりコストを支払って召喚する（「迷わず記述に従う」） |
| 3 | 001・069・070「この効果は重複しない」 | 同名が複数あっても、同じ出来事に1回だけ |
| 4 | 082 で与える効果「この効果で自分はバーストを発動できない」 | 文言どおり：この効果（ライフのコアを置く）でライフが減っても、それをきっかけに自分のバーストは発動できない |
| 5 | 036・X03 連鎖[青]「ターンに1回まで、ネクサス1つを疲労させることで回復できる」 | 中身は【強襲】と同じ。ただし【強襲】ではない（【強襲】を参照する効果の対象外）。発揮は連鎖元の効果を解決した後（連鎖の順） |
| 6 | 077「相手によって破壊されたとき、そのスピリットを手札に戻す」 | 破壊誘発。破壊待機の列の1項目で、破壊時効果も発揮する（既存の「破壊されたとき手札に戻る」と同じ。TIMING_CHART §1.5） |
| 7 | 034 Lv3「合体していない相手のスピリットすべては、可能ならば必ずアタックする」 | アタックできる個体は1体ずつすべてアタックする |
| 8 | 058「このスピリットの効果で相手のデッキを破棄したとき」 | その合体アタックの間、合体スピリットの効果（ホストの効果も含む）で破棄したとき |
| 9 | 063【合体時】「このスピリットが相手によって破壊されたとき」 | 破壊誘発は破壊待機の列で、ブレイヴを残すかの選択より前に解決する（TIMING_CHART §1.5 の手順2→3）ので、ブレイヴを残しても発揮する |
| 10 | X06「相手のブレイヴ/ブレイヴカードすべての合体条件をコスト7以上にする」 | 条件を満たさなくなった合体は即座に分離する（ブレイヴはスピリット状態で残すか、残さなければトラッシュ）。手札のブレイヴカードも新たに合体できない。すでに効果を受けない側と合体しているものは分離しない |
| 11 | 013「お互い、ボイドからコアを増やすことができない」 | ライフも含む（BS18-063 と同じ。手本で決まっていた） |
| 12 | 014「コスト3の相手のスピリットすべてのコア1個ずつ」と紫の【強化】 | Q760 と同じく、対象の中から1体だけ追加で1個（合計+1） |
| 13 | 052「相手のバーストが発動したとき、〜その発動を無効にして破棄する」 | 発動した時点（効果の解決前）に払うかを聞く |
| 14 | 062「このスピリットが紫のシンボルを持つとき」 | ブレイヴのシンボルも含めた合体スピリットのシンボルで判定 |
