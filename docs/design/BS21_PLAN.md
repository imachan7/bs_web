**済み**：バッチ1＝N1・N2・N3（001・041・048・069・070・X04。part797）。「回復できない」の判定は `refreshBlockedByRule`（shared/rules/constraints.ts）1か所で、発生源が効いているかは `hasGlobalConstraint` の match 引数で見る／バッチ2＝N4・N5・N6（014・025・059・064・065。part798）。合体条件にシンボルの色の軸 `braveCondition.symbolColor` も足した（N7 は同じ `instanceSymbolColors` を使う）。「自分の効果で相手を疲労させたとき」は出来事に疲労させた効果の種別（causeType）を渡す／バッチ3＝N7・N8・N9（007・034・062。part799。助っ人として 002 も書いた）。合体スピリットのシンボルの色は `combinedSpiritSymbolColors`（shared/rules/symbols.ts）。相手側へ配る制約は `activeConstraints` の opponentAll ループで、phase/turn は発生源の持ち主から見る／バッチ4＝N10・N11・N12（013・054・058。part800）。合体スピリットのコストは `instBaseCost`（ブレイヴのコストを含む）。デッキ破棄の出来事に原因の発生源を渡し、`bySelfEffectOnly` は合体スピリット全体（ホストとブレイヴ）を自分とみなす（SD15-X01 も同じになった）。`coreGainCap` は sourceTypes を省略すると原因を問わない／バッチ5＝N13・N14（072・080・082。part801）。バーストの発動禁止は `fireBurstOnEvent`（keywords/burst.ts）で battleLock と並べて見る。N14 の `noOwnBurst` は、今のエンジンが自分の効果によるライフ減少でバーストを聞かないため、まだ効き目が無い（自分の効果によるライフ減少でバーストを聞く直しは別にする）／バッチ6＝N15・N16（036・X03・077。part802）。「ターンに1回まで、ネクサスを疲労させることで回復できる」は pay の `oncePerTurn`（【強襲】の limitByKeyword は使わない）。選んだ1体に貸す `targetChoiceLendThisTurn` に filter・side と、aura target・reviveOnDestroy scope の `chosenInstance` を足した。選択から再開したときにマジックのカードIDが消えて何も貸さなかったのを直した（BS13-078・BS12-081 も同じだった）

各バッチは「期待値役（GLM）→ 部品の実装（GLM）→ データ役（Large 4）」。サブは Mistral の API 枠（`~/.config/mistral_api_key`）で回す。既存の器で書ける残りのカードは、バッチ8のあとに色ごとのデータ役でまとめて書く。
