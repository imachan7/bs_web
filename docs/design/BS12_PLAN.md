## 0. この弾の性格

BS10・BS11 に続くブレイヴ弾の3作目。**シンボルの数**を数える・増やす・失わせるカードが集中し、
**【重装甲】**という新キーワードが入る。既存の器で書けるものが7割で、残りが新しい器。

新機構は次の4系統:

1. **【重装甲：色】**（7枚）— 【装甲】の上位。ブレイヴの効果も防ぐ
2. **シンボルの数**（8枚）— 「シンボル◯つを持つスピリット」の絞り込み／追加／喪失／数の比較
3. **【転召：星魂/ボイド】**（5枚）— 転召の「コスト指定」でなく「系統指定」版
4. **バニラ化・バニラ参照**（7枚）— 器は `vanillaAsGrant` があるので既存で書ける

## 1. 確定した解釈（2026-09-03 ユーザー確認）

| # | 論点 | 確定 |
| :-- | :-- | :-- |
| 1 | 【重装甲】は【装甲】の参照に含まれるか | **含まない。完全に別枠**。BS12-067 Lv2「【装甲】を持つ自分のスピリットすべて」は装甲持ちだけに効く（BS12-068 が「【装甲】/【重装甲】」と併記しているのが根拠）。`KEYWORD_INCLUDES` に足さないこと |
| 2 | BS12-X04【重装甲：可変】の「このスピリットの色」 | **付与色も含めて毎回算出**（`instColors`）。既存の【装甲：∞】`colorsFrom:"opponentFieldSymbols"` と同じ再計算の形で `colorsFrom:"selfColors"` を足す。BS12-027 Lv2 との組み合わせが効く |
| 3 | BS12-078 カシオペアシールのデッキ横のコア5個 | **コアは動かさずカウンタだけ持つ**（簡略化）。ボイドから出さない。`data/card-notes.json` に理由を書く |
| 4 | BS12-072 海賊王の秘宝島の主語 | **両陣営**（自分にも効く）。効果文に「相手は」が無いため。既存の主語なし `globalConstraint` と揃える |
