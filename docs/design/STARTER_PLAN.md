## 2. 解釈

調査メモは `STARTER_SURVEY_{redA,redB,white,blue,pyg}.md`。

### 2.1 手順書・前例で決まるもの（確認不要）

- 「アルティメット以外の自分の〜効果」の【強化】は BS19 と同じ `kyoka`（アルティメットはまだいない。BS19-057 と同じ）
- 期間の書かれていない継続の連鎖（SD13-006「ブロックされない」）は、条件を満たす間だけ効く（Q777・Q778。BS19_PLAN §2.1）
- 「BPを比べ相手のスピリットだけを破壊したとき」は相打ちを含まない（BS19_PLAN §2.2）
- 「〜2体を破壊」「3体を回復」で対象が足りないときは、いる分だけ（SD16-005・SD17-013）
- SD10-015「『相手のアタックステップ』でしか使えない」は `ownTurnForbidden` ＋ `mainForbidden`（新しい部品は要らない）
- SD17-015「シンボル1つだけを持つ」に合体スピリットは入らない（ブレイヴのシンボルも数えるので2つ以上）
- SD03-014「効果でスピリットを召喚できない」はスピリットだけ（ブレイヴの召喚は止めない。BS12-072 は「スピリット/ブレイヴ」と明記している）
- **BS10-088 は既存の誤り**：効果文は「ブロックしたスピリット上にコアを置く」なのに、データはネクサス自身に置いている。SD11-012 と同じ部品で直す

### 2.2 確認すること（2026-11-02）

1. SD11-016 バーストブレイク：「メインステップで使えない」は**カード全体**（どちらのモードでも）→ `mainForbidden`
2. SD16-008 鉄壁なる巨人城塞：**自分が破壊されたときは発揮できない**（破壊待機状態では疲労できず、コストが払えない。RULES_BATSPI_WIKI §1）
3. SD13-008 ソウルリープ：**色の置き換え。シンボルの色も変わる**（SEMANTICS_AUDIT §3.9）
4. X009：陣営の書いていない対象は**お互い**（CHOOSER_RULES。聞かなくてよかった）
5. SD11-009 シルバー・ジャッカル：連鎖は「BPを比べ相手のスピリットだけを破壊したとき」が発揮したときだけ動く。**そのバトルが終わるまで、相手はバーストを発動できない**（破壊後のバーストだけでなく、ライフ減少後のバーストも止める）。エンジンはライフが減った瞬間にバーストを発動させるので、データは「バースト封じ → ライフを取る」の順に書く（結果は同じ）
