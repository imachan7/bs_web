## 確かめたいこと

- **009-1** 同時に2体以上が相手の効果で破壊されるとき、相手のアルティメットのコア1個を1回払うだけで全員が残ると読んだ（011-1 の Q4842 に倣う）。体数ぶん払う読みなら、残せるのは払えた回数まで（相手のアルティメットのコアが足りなければ一部が破壊される）
- **012-2** 「相手のアルティメットに破壊されたとき」には、アルティメットのバトルでのBP勝ちによる破壊も、アルティメットの効果による破壊も含むと読んだ。効果による破壊だけなら、アルティメットが相手のスピリットとバトルして勝った破壊では2枚目を捨てさせない
- **014-1** 消滅したスピリットの戻す先は持ち主（相手）のデッキの上で、戻すかどうかは自分が選ぶと読んだ。自分のデッキの上に戻す読み（効果の発揮者のデッキ）ではない
- **016-2** 相手のライフが1個のとき、ライフのコア1個を払うとライフが0になって負けるが、払うこと自体はできると読んだ（`ownLifeOneToVoid` の「結果0になればそのまま勝敗が決まる」と同じ）。払えない読みなら、ライフ1ではアルティメットでブロックできない
- **047-1** 「コスト1以上の自分のスピリット」のコストを、いまのコスト（合体していればブレイヴ分を含む合計・軽減は含まない）と読んだ。055-1・074-2 のコスト比較も同じ測り方にした。本来（印刷）のコストで見る読みなら、合体で変わったコストは無視する
- **054-2** バトルしている相手のアルティメットがいないとき（召喚時のUトリガーに対する【トリガーカウンター】）は、窓は出てブレイヴは召喚できるが■の効果は不発と読んだ。使えるのが「バトルしているアルティメットがいるとき」だけという読みなら、窓にこのカードを出さない
- **066-1** 「できる」を、払わずに召喚するか通常どおり払うかを選べるが、払わない側に損は無いので無償で確定と読んだ。コスト0でもブレイヴの召喚時効果などは変わらない
- **075-1** コストを払わずに召喚したアルティメットのコア（維持コア）の扱いを、ULTIMATE_PLAN は B6（維持コア割れは消滅）としか書いていない。無償召喚で最低Lvぶんのコアをリザーブから置く（足りなければ消滅）と読んだ。置かずに場に出て即消滅する読みなら、075-1 は常に不発になる
