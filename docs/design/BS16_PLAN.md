# BS16「覇王編 第3弾：爆烈の覇道」実装計画

**全90種**（BS16-001〜084 ＋ X01〜X06）。スピリット60 / ネクサス12 / マジック12 / ブレイヴ6、バニラ10枚、各色15枚。
データは `data/staging/BS16.json`（2026-09-18 取り込み・ID の機械検証済み。Wiki の refer は `覇王編 第3弾：爆烈の覇道`）。
BS14・BS15 と同じ覇王編なので【バースト】が主題。**系統「覇皇」「雄将」を参照する札が全色に散っている**。

**同じ Wiki の一覧に載っていたプロモ P069〜P071（多色ブレイヴ3枚）は BS16 に含めない**（2026-09-18 ユーザー指示）。
`P069` の番号のまま `data/staging/PROMO.json` → `data/cards/PROMO.json` に登録する（`loadCards` はディレクトリ内の json を全部読む）。
実装は色の合う BS16 バッチで一緒に行う（P069 赤白→バッチ1、P070 紫黄→バッチ1、P071 緑青→バッチ2）。

**§2.1 は確定（2026-09-18 ユーザー確認）。§2.2 はバッチ着手前に Wiki の公式Q&Aで裏を取り、決まらなかったものだけ聞く。**

---

## 0. 着手前に片付けるもの（BS16 とは別 PR）

**「破壊されたとき」の数え方をエンジンで直す**（§2.1 #1。HANDOFF にあった未決はこれで決着）。
現行の `fireOwnSpiritDestroyed`（removal.ts）は**1体ごとに誘発**するので、2体同時に破壊されると
「1体を手札に戻す」が2回起きる。BS16 の 064・069・038・047・X05 が直撃する。既存カード全般の挙動が変わるので
**BS16 より先に別ブランチ（`fix/` ＋内容）で出す**。どの札が「1体につき」と書いているかの棚卸しから始める。

## 1. データの取り込み

1. 取得済み：`python3 scripts/fetch_wiki_cards.py --set BS16 --refer '覇王編 第3弾：爆烈の覇道' --pages 2`
2. **041 の効果文は Wiki 側でリンクが切れて「Lv1」が別行になっていた**ので、staging で1行に結合済み
   （正：「Lv1の相手のネクサスすべての効果は発揮されない」）
3. 実装は色別 `data/staging/BS16-<色>.json` に分け、最後に `npx tsx scripts/merge-set.ts BS16` で `data/cards/BS16.json` を作る
4. プロモは `merge-set.ts` を通さず、`data/staging/PROMO.json` をそのまま `data/cards/PROMO.json` へ。
   既存に `P` 始まりの cardId は無いので、デッキビルダーの一覧と弾の絞り込みに出るかを確認する

## 2. 解釈

### 2.1 確定（2026-09-18 ユーザー確認）

| # | 論点 | 決定 | 影響 |
| :-- | :-- | :-- | :-- |
| 1 | 「破壊されたとき」で2体以上が同時に破壊された | **誘発は1回**。効果文に数があればその数だけ（「1体を手札に戻す」なら1体だけ）。「1体につき」と書いてあれば体数ぶん | 064 / 069 / 038 / 047 / X05 ＋既存全般 |
| 2 | 【烈神速】（X03） | **【神速】とは別のキーワード**。「【神速】で召喚するとき」（021 / 065）や「【神速】を持つ」（066）には反応しない。**【烈神速】も明示して参照する効果（026「【神速】/【烈神速】を持つ」）には反応する**。コストは「トラッシュのコアすべてを好きに置く」 | X03 ＋参照5枚 |
| 3 | 018 太骨望・X04 ブレイヴァー「このバースト発動時に◯のスピリットが破壊されていたら」 | その破壊で**破壊されたスピリットのどれか1体が◯色**を持てば成立（多色は各色で判定） | 2枚 |
| 4 | 061 暗雲射す鬼ヶ島「破壊できるBPを+1000」 | 「BP◯以下を破壊」の閾値に+1000。**【合体時】の効果・マジックの効果・バースト効果のすべてに効く** | 赤の破壊札全般 |
| 5 | 083 クラッシュ・ザ・バビロン「コスト合計（破壊された自分のスピリットのコスト）まで」 | **合計ではなく1体**。同時に2体以上破壊されたら**発動者が1体を選ぶ**（BS15-084 爆砕轟神掌と同じ）。**合体スピリットはブレイヴのコストを含む**（コスト4のブレイヴと合体したコスト12なら12まで）。**ただしブレイヴをフィールドに残した場合はホストのコストだけ**（8まで。公式Q&A 2024/10/31） | 083 ＋ BS15-084 / X06 の見直し |
| 6 | 070 創造の原典 Lv2「バーストがマジックなら、無償でメイン/フラッシュ効果を発揮できる」 | バースト効果の解決後、**メインかフラッシュの一方**を無償で発揮。**バースト効果によって発揮しているので【氷壁】では無効にできない**（BURST.md §7.1 と同じ） | 1枚 |
| 7 | X01 バゼル「自分のバーストをオープン。条件が【相手の召喚時発揮後】なら発動させる」 | **必ず発動させる**。条件が合わなければデッキの下へ。**実際には召喚が起きていないので、召喚されたスピリットのコストを参照する効果（BS15-X06 サイゴード・ゴレムなど）は不発** | X01 ＋対象の札 |
| 8 | 012 金狐角などで主語が無い効果 | お互いに効く（既存規則。確認済み） | ― |

### 2.2 Q&A で裏を取ってから決める（既存規則で読めるが、細部が割れうる）

- 002 パイルドラコ：「そのスピリットを破壊する」＝**破棄させた相手のスピリット**。「さらに」は同時なので、同じ破棄の残り枚数も止まるか
- 009 百地ダイル：他の「爬獣」の Lv ごとのBPを**このスピリットの現在BP（BP+込み）**に書き換える。書き換え後のBP+は加算（BS15 X05 カグヤ Q3629 と同型）
- 036 ジャンヌ／079 ムーンボウクローク「【氷壁】と同じ色」：【氷壁：赤/紫/緑/白】なら**そのどれか1色を持つ**相手のスピリット
- 039 ラプンツェル「1度に10枚以上破棄されたとき、5枚までを好きな順番でデッキの上へ」：順番の選択は BS15-082 の器を流用
- 045 オフィエル「バーストを破棄することで、ライフが5になるように」：ライフ5以上なら**払えない**（COST_MODEL の「ことで」）
- 064 五行山 Lv2「『召喚時』効果を持つ」＝カード自身の効果文に『このスピリットの召喚時』があるか（Lv を問わない）
- 067 氷聖女の塔 Lv2「コア2個を置かなければバーストをセットできない」：**セット1回ごとに**支払う
- 080 次元断：「このバトルの間、自分のライフを減らした相手のスピリット」を**バトル単位で記録**する必要がある
- X04 ブレイヴァー 合体時「相手の手札が増えたとき」：**増えるたび**に1回（ドロー1回・手札に戻す1回がそれぞれ1回）
- X05 オズ「相手のスピリットすべてを好きな順番でデッキの上に」：合体スピリットのブレイヴも戻す
- P070 リクゴー（BPの高い方が破壊）と 082 マギアゲフリュスター（Lvで比べる）が同じバトルで重なったとき：後から発揮した方を優先と読む（RULES_BATSPI_WIKI の競合規則）。裏が取れなければ聞く

### 2.3 既存規則で決める（確認不要）

- 012 金狐角「スピリットすべては手札に戻らない」は主語なし＝**お互い**（BS15 §2.3 #19）
- 074・076・078・080・082・083「その後コストを支払うことで、フラッシュ効果を発揮」は BS14 のバーストマジックの器（BURST.md）
- 「BPを比べ相手のスピリットだけを破壊したとき」「疲労状態でブロックできる」「Lv1として扱う」「【重装甲】【氷壁】【強襲】【不死】【覚醒】【激突】【光芒】」は既存
- X04 Lv1「このターン相手が1回もアタックしていなかったら」は BS04-050 と同じ判定
