# BS16「覇王編 第3弾：爆烈の覇道」実装計画

**全90種**（BS16-001〜084 ＋ X01〜X06）。スピリット60 / ネクサス12 / マジック12 / ブレイヴ6、バニラ10枚、各色15枚。
データは `data/staging/BS16.json`（2026-09-18 取り込み・ID の機械検証済み。Wiki の refer は `覇王編 第3弾：爆烈の覇道`）。
BS14・BS15 と同じ覇王編なので【バースト】が主題。**系統「覇皇」「雄将」を参照する札が全色に散っている**。

**同じ Wiki の一覧に載っていたプロモ P069〜P071（多色ブレイヴ3枚）は BS16 に含めない**（2026-09-18 ユーザー指示）。
`P069` の番号のまま `data/staging/PROMO.json` → `data/cards/PROMO.json` に登録する（`loadCards` はディレクトリ内の json を全部読む）。
実装は色の合う BS16 バッチで一緒に行う（P069 赤白→バッチ1、P070 紫黄→バッチ1、P071 緑青→バッチ2）。

**§2.1 は確定（2026-09-18 ユーザー確認）。§2.2 は公式Q&Aで裏を取り済み（2026-09-21）。残りは §2.5。**

## 0. 着手前に片付けるもの（BS16 とは別 PR）

**「破壊されたとき」の数え方をエンジンで直す**（§2.1 #1。HANDOFF にあった未決はこれで決着）。
現行の `fireOwnSpiritDestroyed`（removal.ts）は**1体ごとに誘発**するので、2体同時に破壊されると
「1体を手札に戻す」が2回起きる。BS16 の 064・069・038・047・X05 が直撃する。既存カード全般の挙動が変わるので
**BS16 より先に別ブランチ（`fix/` ＋内容）で出す**。どの札が「1体につき」と書いているかの棚卸しから始める。

## 1. データの取り込み

1. 取得済み：`python3 scripts/fetch_wiki_cards.py --set BS16 --refer '覇王編 第3弾：爆烈の覇道' --pages 2`
2. **041 の効果文は Wiki 側でリンクが切れて「Lv1」が別行になっていた**ので、staging で1行に結合済み
   （正：「Lv1の相手のネクサスすべての効果は発揮されない」）
3. 実装は色別 `data/staging/BS16-<色>.json` に分け、最後に `npx tsx scripts/merge-set.ts BS16` で `data/cards/BS16.json` を作る
4. プロモは `merge-set.ts` を通さず、`data/staging/PROMO.json` をそのまま `data/cards/PROMO.json` へ。
   既存に `P` 始まりの cardId は無いので、デッキビルダーの一覧と弾の絞り込みに出るかを確認する

### 2.4 Q&A で見つかった一般則（BS16 以外にも効く。⚠️ 実装を確認すること）

- **「〜することで、〜する」は、後半が解決できなければコストも払えない**（006 Q3649／008 Q3655／018 Q3672／063 Q22385）。COST_MODEL の既存規則どおり。バーストマジックの「その後コストを支払うことで、フラッシュ効果」は**前半が不発でも払える**（074 Q25017／076 Q25021／078 Q25025）
- ⚠️ **効果で複数体を同時に召喚したら、召喚は1回**：転召の祭壇（SD02-013）の+1コストは**1回だけ**（009 Q3657／044 Q3718／X05 Q3753）。現行の `shared/cost.ts` の `opponentSummonCostIncrease` は召喚ごとに足すので、**複数体召喚の器で1回に抑えているか確認する**
- コストの支払いで消滅したカードは、その召喚の召喚時効果の時点ではまだトラッシュに無い（011/012 Q3658/Q3659、056 Q17816/Q17817）
- 「〜1体につき」「〜の数」は**このスピリット自身も数える**（017 Q3667／X02 Q3742／040 Q3710／X05 Q3751）
- 070 創造の原典：無償になるのは**メイン/フラッシュ効果のコストだけ**で、バースト効果内の「〜ことで」は払う。バーストからの発揮は**マジックの「使用」ではない**（力奪う凱旋門・X06 Lv3 でも止まらない）（Q22399 / Q22400 / Q3755）
- 【烈神速】は「スピリットの効果」扱い：コア移動を1個に制限する相手の効果があると使えない（Q22409）。065 Lv2 は X03 のバトル中、**どのバースト条件も**発動不可（Q22388）
- 021 ノウゼンサーバル：【神速】召喚の支払い時に疲労させて2コストぶん、残りはコアで払ってよい。2体で4コスト。**【神速】以外の召喚には使えない**（Q3673〜Q3676）
- 068 階段山脈 Lv2：スピリット/ブレイヴの召喚だけ（マジック不可）。配置したターンに破壊されてもターン終了時の回復は起きる（Q22394〜Q22396）
- 082 マギアゲフリュスター：そのターンずっと Lv で比べ、「BPを比べ〜破壊したとき」は**発揮しない**（Q25032 / Q25033）
- 059 カイメイジュー：指定されたスピリットは、ブレイヴがバトル中に破壊されてもそのバトルの間ブロックできない（Q20182）
- 066 浮遊関：スピリット状態のブレイヴは対象になるが、合体スピリットには【合体時】以外の効果は与えられない（Q22390）

### 2.6 ユーザー確認で確定（2026-09-21）

- **002 パイルドラコ**「自分のデッキは破棄されない」は**自分の効果による破棄も止める**（原文に「相手の」が無い）。
  ミノガメンの `noDeckMillForPidThisTurn` は相手の効果だけなので、別の軸が要る
- **009 百地ダイル**：他の「爬獣」のBPは**百地ダイルの現在BPそのもの**。その爬獣自身が受けるBP+は**足さない**
  （BP上昇は百地ダイルに掛けないと意味が無い）
- **080 次元断**のフラッシュは、使うときに「このバトルで自分のライフを減らした相手のスピリット」（`BattleState.lifeDamagers`）か「このバースト発動時に減らしたスピリット」（`burstEventLifeDamagerId`）のどちらかを選び、1体を破壊する。バトル外なら前者は対象なし（2026-09-22）
- **058 サテライド・バード**：バーストの発動は止めず、その中の**スピリット**召喚だけ不発。ブレイヴの召喚は止めない。お互いに効く（2026-09-22）
- **027 リョフ・ビートル Lv2-3**：このスピリットのアタック中、バトル・効果を問わず相手のスピリットが破壊されるたびに誘発。「同じ系統」は1つでも共有すれば該当（2026-09-22）
- **X03【烈神速】の「トラッシュのコアすべてを好きなように置く」**は対戦者に選ばせる（簡略化しない）。コア1個ずつ置き先（リザーブ／自分のスピリット・ネクサス／**召喚するこのスピリット**）を選び、一括ボタン（全部リザーブ／全部このスピリット）も出す（2026-09-22）。
  「置くことで召喚する」は「〜ことで」なので、**X03 がLv1を維持できない置き方は選べない**（残りがLv1コストちょうどになったら置き先はこのスピリットだけ。COST_MODEL の一般則。2026-09-22 ユーザー確認）
