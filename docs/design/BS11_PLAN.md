## 2. ⚠️ 実装前に決めることリスト（推測で書かない）

### 2.1 分離のコアの分け直し（最重要。5枚＋ブレイヴ全般に効く）

BS11-015 冥王神獣インフェルド・ハデス／BS11-034 星馬コルット：
「相手の合体スピリット1体を**分離させる**。ただし、**分離するときのコアの移動は相手が行う**」。

現在の `detachBrave`（[BRAVE.md](./BRAVE.md) §12.5）は「**コアは要らない**」＝コアを動かさず
ホストに全部残す形になっている。だが上の効果文は**コアが移動すること**を前提にしていて、
その分け方を**相手（＝合体スピリットの持ち主）が決める**と書いてある。

**解釈案**：分離すると合体スピリット上のコアを**ホストとブレイヴに分け直す**（総数は変わらない）。
どちらも Lv1維持コア以上を確保できなければ、確保できない側が消滅する。
分け方は持ち主が決める（対話では1個ずつ選ばせる。クロノ・ボロス＝`coresDownToLimit` と同じ形）。

**→ ユーザー確認待ち。** 併せて BRAVE.md §6.3（ホストが場を離れるときの分離＝段階5）も
同じ手順に乗るはずなので、ここを決めると段階5がまとめて進む。

### 2.2 ブレイヴだけを破壊する（2枚）

BS11-014 切り裂き姫アゼイリア「相手の合体スピリットの**ブレイヴ1つ**を破壊する」／
BS11-016 邪眼皇ゼナス「相手の合体スピリット**すべてのブレイヴ1つずつ**を破壊する」。

**解釈案**：合体中のブレイヴだけをトラッシュへ送り、ホストは場に残る。ブレイヴの破壊なので
『破壊時』の誘発は引く。コアは §2.1 の分け直しに従う（ブレイヴ側に載っていたぶんはホストへ）。

## 3. 進め方

BS10 と同じく**色ごとのバッチ**で、1バッチずつ「構造化 → 検証全緑 → コミット」。
カードプールには**実装済みのものだけ**を入れる（`data/cards/BS11.json` に足す）。

検証の定型（バッチ完了時に1回）:

```
npm run typecheck && npm run validate:cards && npm run validate:notes && npm run validate:gaps && npm run smoke:quiet && npm run build:client
```
