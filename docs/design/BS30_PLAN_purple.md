- **【毒刃：N】の読み（013 で共通。BS27・BS28・BS29 の表と同じ）**：相手のデッキの上から N 枚を裏向きで相手のスピリット/アルティメットの下に置く。置き先は置く側が好きなように割り振る。デッキが N 枚に満たなければある分だけ。置き先がいなければ置かない。デッキ破棄ではない（ULTIMATE_PLAN C2 と同じ扱い）。下のカードはそのスピリット/アルティメットが場を離れるとき持ち主のトラッシュへ破棄する
- **この弾のブレイヴ（057・058・CP14-X16）と合体**：ブレイヴは合体条件にアルティメットと書かれたものだけがアルティメットに合体できる（ULTIMATE_PLAN B13・Q358・Q360）。057（コスト3以上のスピリット/アルティメット）・CP14-X16（同）は書かれているのでアルティメットに合体できる。058（コスト4以上のアルティメット）はアルティメットにだけ合体できる。【合体時】の節はホスト（合体している間のスピリット/アルティメット）の効果で、アルティメットに当たるかは各行に書いた。合体中のブレイヴの【合体時】でない効果（Lv の書かれた効果）は働かない（BRAVE.md §12 の8。ただし『このブレイヴの召喚時』は例外）
- **ブレイヴのシンボル**：057 と CP14-X16 はシンボルを持たないので、軽減シンボルに数えられず、スピリット状態でアタックしてブロックされなくてもライフを減らせない（Q20499・Q20500・Q19823・Q19824）。058 は紫のシンボルを持つ
- **軽減シンボル**：この弾の紫には軽減シンボル[極]を持つカードが無い（staging の reduction は紫だけ）ので、`-0` の行は無い

## 確かめたいこと

- **012-1** 「デッキを上から6枚破棄し、トラッシュにある剣刃のブレイヴを、好きなだけ召喚できる」は、私は「6枚は必ず破棄し、続けて（破棄した札も含めて）召喚するか選ぶ」と読みました。CONJUNCTION の「Aし、Bできる」は両方行うかどちらも行わないかとあるので、これを当てると「召喚しないなら破棄もしない」になります（破棄しないでおけば6枚が捨てられない。ただし破棄した札から剣刃が出ることを見込んで選ぶことはできなくなる）。どちらですか
- **009-1** 「3枚破棄し、1枚ドローする」は「さらに」と同じ同時ですが、私は「破棄を先に処理し、ドローは破棄後の一番上」と読みました。破棄の前の一番上を引くなら、引くカードが変わります
- **008-2** 「それらのスピリットカード/アルティメットカードすべてを…召喚できる」は、私は「置かれた札のうち召喚できるものを、1枚ずつ召喚するか選ぶ」と読みました。「全部召喚するか、ゼロか」だと、スピリットが満員のときなどの結果が変わります
- **058-3** 借りたUトリガーを、いつ・誰のコストで判定して発揮するかは、私は「合体アタック時に1つ選び、書かれたタイミング（アタック時はすぐ、バトル時はバトル時）に、このアルティメット（合体のコストを含む）のものとして発揮する」と読みました。Q20504（バトル時のUトリガーも発揮できる）・Q20502（合体でコスト+2）から。ヒット判定を借りる元のコストで行うなら、ヒットするかが変わります
