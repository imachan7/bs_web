判定の基準：「既存で書ける」は**型にフィールドが実在し、同じ書き方の実カードが data/cards にあるものだけ**。実例が部品ごとにしか無いものは備考に明記した。
`STANDARD_POOL_ONLY`（scripts/validate-cards.ts:647）の action は 26系専用で実例が無いため「型はあるが実例なし」扱い（今回は該当なし。`symbolWhenSummoning` は action でなく kind だが、データに実例0件なので同じ扱い）。

## 判断が割れる点・仕様の不明点

- **#1（081）**：PLAN §2 の「timedEffect all＋filter level＝declared で書ける」は、**いまの型では書けない**（declare に level が無い・timedEffect に「効果を失う」が無い）。①`declare.what:"level"`＋`TimedContent.effectsDisabled` を足す（私の推奨。declared の置き換えに乗れる）か、②BS07-081 の `lendSelfThisTurn`＋`spiritEffectsDisabledGrant` に `targetLevel` を足すか（declare の値が仮想発生源へ渡らず不可）。①でよいか。「新たに得ることもない」は、効果を失う個体が後から付与されたキーワード・効果も止める（`effectsDisabledContinuous` の既存の意味）でよいか
- **#4（032）**：「このバーストが相手のメインステップに発動したとき、召喚する。その後、相手のメインステップを終了する。」の条件は**両方**にかかる読み（メインステップ以外では何もしない）でよいか。召喚だけ無条件で終了だけ条件つき、という読みもありうる。いずれも発動自体はする
- **#5（034）**：「破壊したスピリット1体をデッキの上に戻す」は、トラッシュに落ちたカードを対象にする読みでよいか（記録が無い・既にトラッシュから動いているときは不発）。BP比較で相手だけ破壊の場面に限る（相打ちは対象なし）
- **#6（067）**：「このネクサスのシンボルを白のシンボル2つにする」を、ネクサスの元の白1つ＋追加1つ（`symbolWhenSummoning`）で書いてよいか。固定（`symbolFix`）と違い軽減計算にだけ効く。BS16-068（スピリット/ブレイヴ両方）は召喚するカードの種別を見ない簡略のままだが、067 はブレイヴだけなのでこのままでは書けない
- **#9（074）**：フラッシュ部の「同じカード名で2体以上いる相手のスピリット1体を指定」は、**2体以上いるものだけを候補にする**読みでよいか（いなければ不発）。バースト部のネクサスの指定は相手のネクサスすべてが候補（1体でも指定可）。指定は使用者が相手の場から選ぶ
- **#10（009）**：BP差は「勝った側の実効BP − 破壊直前の負けた側の実効BP」でよいか（`lastBattleDestroyedBp` は破壊直前に測る既存の記録）。【装甲】等でBP比較に勝っても破壊されない場合はバトル勝利にならず不発
- **#12（060/068）**：①060 の「発揮できない」は §2 で確定（払うかは相手が選び、コスト支払い・発動は成立。マジックはトラッシュへ）。**068 はバーストの発動宣言・バーストエリアからトラッシュへ行く処理は成立し、効果の解決だけを止める**でよいか（BS17_SURVEY_green_white の確認事項4と同じ）。②払えない場合（手札に条件を満たすカードが無い・リザーブが2個未満）は自動で不発でよいか。③関門を新しい `kind` にするか、`magicNegate` の「向きを逆にした版」にするかは設計判断（私は `pay` を再利用する関門1つを推奨）
- **#13（084）**：「バースト効果を発揮できない」は、バースト自体は発動する（バーストカードはトラッシュへ行く・バースト誘発は起きる）が効果だけ飛ばす、でよいか。`battleLock{lock:"burst"}`（「発動できない」）とは別。マジックの【バースト】とスピリットの【バースト】（召喚するだけ）の両方が対象でよいか。`declare cost` の候補（options）の上限はいくつにするか（BS14-114 は 0〜4）
- **#14（043）**：§2 のとおり「発揮」だが、**発揮後のカードの行き先**（手札に残る／トラッシュへ）と、**効果文に無い使用回数**（アタック中何回でも？）が未確認。手札のカードは払ったコスト分のコア移動後も手札に残る読みでよいか。操作は「バースト効果を使う」ボタン別アクション（§2）
- **#15（051/X06）**：「ライフ3以下なら通常どおり減らす」（§2）に加え、①置換を選んだとき**ライフの減少扱い**にならない（`ownLifeDamaged`・【聖命】等が誘発しない）でよいか ②置いたコアはリザーブへ（効果文どおり。ボイドではない）③アタックが「ライフを減らす」前提なので、ブロックされたときは置換が起きない
- **#16（004）**：場のスピリットがフィールドを離れる手順（ACTION_VOCABULARY §2）として、バウンス待機を通る（「フィールドを離れるとき」誘発が起きる）でよいか。バーストとしてセットしたとき「バーストをセットしたとき」（`ownBurstSet`）は誘発する読みでよいか
- **#17（049）**：見えた内容を**そのターン中・その相手のバーストが入れ替わるまで**持ち主の画面に出し続けるか、1回の確認ダイアログで閉じるか（`peekedOpponentCardIds` は積みっぱなし）
- **#18（083）**：「マジックカードは使用できない」の範囲は**手札のマジックだけ**か、手元（tegamoto）・トラッシュからの使用も含むか（`cantUseHandCardsForPid` は手札のカードを対象にする）。「召喚時効果を発揮したスピリット/ブレイヴの色」はそのバーストのきっかけの1回ぶんでよいか（多色は全色＝§2）
- **#19（063）**：「相手のスピリット/ブレイヴ/ネクサスの効果では」＝**マジック由来は対象外**でよいか。「ターンに1個まで」は**相手プレイヤー全体の累計**（どのスピリットの効果でも合わせて1個）でよいか。置き先「ライフ/フィールド/リザーブ」へのコア配置すべてが対象で、コアステップ・コスト支払いは対象外（効果ではない）
- **#20（014）**：「ボイドから相手のライフにコアが置かれた」は、**相手自身の【聖命】**など相手の効果によるものも、自分の効果で相手のライフにコアを置く動作も含むでよいか（原因を問わない読み）
- **#21（062）**：疲労させるのは発生源のネクサス自身。「本来のコストが8以上」は印刷コスト（§2）。召喚の軽減（シンボル）を適用した後の残りコストから最大2を肩代わりする読みでよいか。ブレイヴ・ダイレクトブレイヴの召喚にも効くか（効果文はスピリットカードのみ）
- **#2（070）**：`ownDeckMilled` は破棄の**後**に発火する。バースト持ちマジックの `onMilledFromDeck`（自分で無償発動）が先に取り除くので、残ったバースト持ちだけが手札に加わる順（mill.ts の既存順）でよいか
- **共通**：#10・#11・#15・#9 は軸を足す先の型ファイルが `types/effectAction.ts`（179KB）に集まる。新しい kind は `effectDef*.ts` の該当ファイル、ハンドラの置き場は docs/design/WHERE_TO_ADD.md を見てから決める
