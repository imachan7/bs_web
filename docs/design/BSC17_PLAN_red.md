# BSC17 処理順の表：赤

- 対象：BSC17-001 BSC17-002 BSC17-X01。調査役（Sonnet）が 2026-11-26 に作成。**ユーザー確認待ち**
- BSC17（オールキラブースター【眩き究極の王者】）の新規18枚はすべてアルティメット。同名の既存カード・主弾の表に同じカードは無い（アルティメット・ブレイドラ／ソードマスター・ドラゴン／バゼルは BSC17 が初出）。全節を表にした
- Q番号は batspi Wiki の各カードページ（2026-11-26 取得）。Q&A が見つかったのは 001（Q19570・Q19571）・002（Q19572〜Q19575）・X01（Q19612〜Q19616）。回答が「汎用編を参照」だけの Q（Q19570・Q19572〜Q19574・Q19612・Q19613）は根拠に使わない
- 全カード共通：「スピリット」を対象・範囲・数にする節はアルティメットに当たらない（ULTIMATE_PLAN B1・B7）。アルティメットの効果は【装甲】で防げない（B10）。Uトリガーは ULTIMATE_PLAN §3 の段1〜6。ヒット判定は置いた札の印刷コスト＜このアルティメットの今のコスト（C3）。001 はコスト1（ヒットするのはコスト0の札だけ）、002 と X01 はコスト7（6以下がヒット）
- BSC17 のブロックアイコンは《1》。バーストの「召喚する」は無償（CONFIRMED_RULES §7）

## 確かめたいこと

- **002-2** 【真・激突】はアルティメットにも義務を課す、と読んだ（BS25-052-2 と同じ）。【激突】は B4 でアルティメットが義務を負わないが、【真・激突】は「スピリット/アルティメットで」と書かれている。汎用編の【真・激突】編（Q19572 の参照先）は読めていない。アルティメットだけがブロックできる盤面の期待が変わる
- **X01-2** バーストの破壊の対象（BP6000以下の相手のスピリットも相手のネクサスも）が両方いないとき、「この効果発揮後」の召喚は行う、と読んだ（発揮したものとして）。行わないなら、対象なしの盤面のテストの期待が逆になる
