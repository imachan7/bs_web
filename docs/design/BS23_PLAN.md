## 5. 既知の限界

- 075「相手は〜2体を破壊する」は1体ずつ選んで破壊する（同時に2体を選ぶ器が無い。エンジン全体の複数体の選択と同じ）
- X01 が離れて合体数があふれたとき、外すブレイヴは最後に合体したもの（Q4588 は持ち主が選ぶ）
- 056 が先に通常の枠で合体し、後から 055 が合体した場合も、056 を追加の枠として数える（上限2以上のホストだけで差が出る）
- 043 自身の【聖命】は印の keyword で持たせたので、手札・トラッシュでも「【聖命】を持つ」に数えられる（Q4557 とずれる）
- X01 の「【強化】を持つものとして扱う」と Lv3 の【強化】付与は未実装（`kyokaBonus` が付与先を数えない）
- バトル終了時に破壊する効果（BS16-075 スケープゴートも）が、ブロックされずにライフで受けたときにも破壊するようになった（以前はブロックの解決の経路だけ。効果文どおりの直し）
- X07 は効果による召喚を、コストを払う形でも一律に止める。X13-12 は効果によるコストなしの召喚には破棄を課さない。X13-12 で破棄するカードを選ぶ画面は無い（省略時は条件に合う手札の末尾から）
- 003 はライフ数を召喚する時点で読み、最初に召喚した該当カード1枚で使い切る（召喚するときに当てるかを選べない）
- 084 のネクサスの肩代わりは、召喚の支払い画面の補助（【神速】の肩代わりと同じ欄）に出る。クライアントでの動作は未確認
- 003 は効果によるコストなしの召喚で該当カードを出しても使い切る
- X13-12 の破棄は手札からの召喚だけで見る（手元から召喚する経路では見ていない。今のプールで X13-12 を手元に置く手段は無い）
- 期待値の場面が無い節：003【強化】、068 の印刷コスト判定（Q22544）、X07【合体時】、031 Lv2 の疲労ブロック、X01 のアタック時、084 と X07 の併用
- B4 の新しい誘発（027 の【連鎖】の色・ブロック、033 の連鎖ドロー、X05 の BP0 で破壊）は全カードの火入れ（part197）で場面が組めず、`data/fieldevent-fire-baseline.json` に入れた。挙動は part842〜844 で見ている
- 【連鎖】の節の見分けは、発生源とブレイヴの keyword:"rensa" エントリの action と JSON で一致するかで見る。X05 の「このバトルの間 BP0 で破壊」は、合体アタック中だけ有効な常時の誘発で近似（合体アタック時の効果が止められても破壊だけ効く場面は拾えない）。041「ターンで初めて」は発生源ごとのターン1回で近似。X05 の無償召喚は Lv1 召喚だけ・ボイドの通行料（BS22-012）を見ない
- 033【合体時】Lv2（BP6000以下を手札に戻す）は未実装（部品の要らない節。色ごとのバッチで入れる）
- B5：X06 のブロック時の手札破棄は、破棄するカードを選ばせず先頭の1枚（既存の discardMagic と同じ）。X06 のバーストの発動コストは支払い元を選ばせず自動（リザーブ→ネクサス→コアの多いスピリット）。X06 の2色のシンボルは1色目で決め打ち。072 の「コアを置けない」は発生源の効果が無効にされる場合を見ず、リンクのコアの選択・ソウルコアの入れ替えの経路には入れていない。072 の「コア5個以上」は Lv2 で代用。072-e2・X06-e1 も火入れの基準に入れた
- B5 見直し：X06 のシンボル2つは合体中のブレイヴのシンボルを変えない。072-e2 はアトライア海帝国で払った分を召喚コストから除く扱い（Q22557）を見ていない。053 の【連鎖】は既存の連鎖カードと同じ if の形なので、連鎖の条件を無視する効果（SD11-X02）は効かない（既存の連鎖カード共通）
- B6：013・047 の「破壊して払ったことにする」は、破壊が効かない（破壊されない）場合も割引だけ残る。【神速】の無償確認で中断して再開すると破壊の指定は引き継がれない。013 で引くのはブレイヴの印刷コスト
- 赤：X01「このカードは【強化】を持つものとして扱う」（場の外）は未実装（場の外で【強化】を参照するカードがプールに無い）。付与された【強化】は1体につき1つに丸める（X01 が2体いても重ならない）。付与する【強化】に「アルティメット以外」の条件を付けていない。004 のコスト-2 は「疲労させて2まで肩代わり」の器で書いた。002-e2（合体中の fieldEvent）も火入れの基準に入れた
- 「召喚時効果は発揮されない」召喚では、ほかのカードの「〜が召喚されたとき」も止まる（既存の skipOnSummon の作り。2026-08-17）。005 のトラッシュからの戻りも、062・063・X07・X05 で出したスピリットでは起きない。**2026-11-08 ユーザー確認：止めるのは召喚されたスピリット自身の召喚時効果だけ。直しは HANDOFF のエンジンの直し①**
- 紫：X02 召喚時の「相手のスピリットのコア3個」は1体から取る形（複数体から分けて取れない。分けると「0個になった体数」が数えられない）。058 の「出るまでオープン」はデッキを上から破棄して見つけた1枚をトラッシュから手札へ戻す形（見つけたカードも一度「破棄された」扱いになる）。【強化】（コア除去+1）が「この効果で0個にはできない」付きの数値の除去にも効くよう直した（Q761 が除くのは「1個残して残りすべて」だけ。既存の BS06-014 スモッグゴート・SD01-013 冥剣士ベリト・BS18-056 にも効くようになる）
