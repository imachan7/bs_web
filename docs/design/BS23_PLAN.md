# BS23 実装計画（剣刃編 第5弾：剣刃神話）

データは `data/staging/BS23.json`（2026-11-07 取り込み。`python3 scripts/fetch_wiki_cards.py --set BS23 --refer '剣刃編 第5弾：剣刃神話' --pages 2 --out data/staging/BS23.json`）。番号の抜け・重複なし。
**対象は95枚**：BS23-001〜084・X01〜X08（赤17・紫15・緑14・白15・黄15・青15。多色は 009 赤緑・018 紫赤・027 緑白・045 黄赤）と、一覧に混ざっている X13-10〜12 の3枚。効果文が空は 029・040。
新しいキーワードは【抜刀】（002・005・016・024・026・033・044・050・052 ほか。062・063・074 が参照）。ほかは既存（【合体時】【強化】【連鎖】【分身】【神速】【聖命】【激突】【重装甲】）。
進め方は BS22 と同じ（調査役 → 確認 → 期待値役 → 実装役 → データ役 → `merge-set.ts`）。

## 1. 手順書・公式Q&Aで決まるもの（確認不要）

| 節 | 決め手 |
| :-- | :-- |
| 【抜刀】の中身 | 手札の、そのスピリットと合体可能な系統「剣刃」のブレイヴ1枚をコストを払わず召喚できる（Q794）。召喚時とアタック時（BPを比べ相手のスピリットだけを破壊したとき）の2種 |
| 【抜刀】で出すブレイヴの置き方 | スピリット状態でも（Q795）、【抜刀】を発揮したスピリット以外への直接合体でも（Q796）よい。ブレイヴの召喚時効果は発揮される（Q797） |
| 「合体可能な」の判定 | ブレイヴの合体条件が【抜刀】を持つスピリットに合うかだけを見る。合体禁止中でもスピリット状態で出せる（Q798）。合体済みでもスピリット状態で出せる（Q799） |
| 合体条件のコスト | 合体できるブレイヴ数が埋まっていれば元のコスト（Q800）、空きがあれば合体中のブレイヴを含めた合計（Q802） |
| 手元のブレイヴ | 出せない（Q801） |
