# 誰が選ぶか（「相手は、〜する」の扱い）

同じ規則を3枚で3回発見し直した（【暴風】→ ブリシンガメンの首飾り → ダークスカルデーモン）ため、
規則として1か所に書く。

## 1. 基本規則

> カードテキストの**主語が「相手は」なら、対象を選ぶのは相手**。
> ただし**解決は発生源の持ち主の効果として行う**（装甲・効果耐性・「相手の効果で〜」の判定は発生源基準）。

「自分のスピリット1体を破壊する」（主語が自分）と
「**相手は**、相手のスピリット1体を破壊する」は**別物**。後者を自動選択や発生源の持ち主による選択で
実装すると、**相手の場から都合の良い1体を選べる＝印刷されたカードより強くなる**。

### 例外：選択を伴わない「相手は」

「相手は、〜**できない**」は制約であって選択ではない。この規則の対象外。
（力奪う凱旋門＝マジックを使用できない、夢想法師サンゾール＝ターンに1体しか召喚できない）

## 1.5 対象を「変更できる」効果は、**変更する側の持ち主**が選ぶ（2026-08-15 ユーザー確認）

封印された魔導書Lv1（BS02-087）の「お互いを対象としたマジックの効果は、効果の対象を
相手のみ、または自分のみに変更できる」のように、**他人の効果の対象を書き換える**効果は、
書き換える側（＝発生源）の持ち主が選ぶ。**マジックの使用者ではない**。

| 論点 | 確定した規則 |
| :-- | :-- |
| 選ぶ人 | **発生源の持ち主**。相手が使ったマジックにも効く（『自分のターン』中に相手がフラッシュで使った場合） |
| 選択肢 | **3択**（変更しない／相手のみ／自分のみ）。「変更**できる**」なので変更しない選択も残す |
| 「相手」「自分」の向き | どちらも**持ち主から見た**呼び方（使用者から見た向きではない） |
| 聞く回数 | **マジック1枚につき1回**。答えはそのマジックの解決中ずっと使い回す |
| 効く範囲 | 「お互いを対象」（`side:"both"` 等）に加えて、**陣営を指定していない対象**＝`anySide` の「スピリット1体」「スピリットすべて」も含む |
| 聞く条件 | そのマジックが実際に上の範囲に触れるときだけ。相手だけを対象にする大多数のマジックでは確認を出さない |

実装は `GameState.magicSideDecision`（**対象として残る側の PlayerId**。null＝変更しない）。
持ち主から見た「自分／相手」ではなく残す側の pid をそのまま持つのは、持ち主と使用者が
別人でありうるため。`bothSidesPids` と `bothSidesRedirectKeepPid` がこれを読む。
**非対話（テスト・自動解決）ではセットされず、従来どおり持ち主に有利な側へ自動で固定する**。

## 2. 実装の形

`PendingChoice.pid` が**選択者**、`actorPid` が**解決の主体**。両者が異なるときだけ `actorPid` が入る。

```ts
requestChoice(
    state, owner, prompt, candidates, false, action, self,
    "target", undefined,
    action.chooserIsTarget ? opp : undefined,   // ← 選択者だけ相手に差し替える
)
```

カード側は `chooserIsTarget: true` を書く。手札・トラッシュから選ばせる場合は
`requestCardChoice` の `pid` に選択者を渡す（`discardOpponent.forcedTargetPid` がその形）。

**非対話（smoke）の自動選択は「相手が選ぶなら選ぶであろうもの」＝相手にとって損の小さいものにする。**
実対戦は常に `interactiveTargets = true` なので、これはテストの決定性のためだけの規約。

## 3. 現状の適合状況（2026-08-13 時点）

効果文に「相手は、」を含むカードは **22枚**。

| 状態 | 枚数 | 内訳 |
| :-- | :-- | :-- |
| ✅ `chooserIsTarget` で相手が選ぶ | 14 | `exhaust`（【暴風】12枚）／`returnToDeckTop`（ブリシンガメン）／`coreToOpponentTrashChoice`（ダークスカルデーモン） |
| ✅ `forcedTargetPid` で相手が選ぶ | 2 | `discardOpponent`（マッチュラ・ツクシンモア） |
| ✅ 制約なので対象外 | 3 | 力奪う凱旋門・夢想法師サンゾール・大風車の丘（【暴風】のテキスト置換） |
| ✅ 1体（1個）ずつ相手に選ばせる | 3 | 下表。2026-08-13 に修正（smoke part176） |

| カード | アクション | 直す前の自動選択 | 向き |
| :-- | :-- | :-- | :-- |
| BS08-069 ジャッジメントフレア | `destroyDownToOwnCount` | 実効BP**最大**から破壊 | **印刷より強かった**（相手なら弱いのを差し出す） |
| BS08-072 マインドブレイク | `costOwnSpiritCoresToTrashThenOpponent` | コア**最多**のスピリットから5個 | **印刷より強かった** |
| BS04-114 タイダルタイド | `sacrificeOwnNexusesThenEnemyDestroysOwn` | 実効BP最小から破壊 | ほぼ等価（相手も同じ選択をする） |

マインドブレイクは**前半と後半で選択者が入れ替わる**：前半「自分のスピリット上のコア5個を置くことで」は
コストなので支払う本人が選び（COST_MODEL.md §2）、後半「相手は、〜置く」は相手が選ぶ。

**これで「相手は、」を含む22枚すべてが規則に適合した。**

## 4. 新しいカードを実装するときの手順

1. 効果文の主語を見る。「相手は」なら §1
2. 既に `chooserIsTarget` を持つアクションならそれを書く。無ければアクションに足す
   （型・ハンドラ・カードデータの3層。既存3アクションが手本）
3. `selfMode` に注意。`anySpiritAttacked` のようにイベント対象を `self` に差し替える経路では
   `owner` がイベント側になり、「相手」の向きが逆さまになる（ダークスカルデーモンで実際に踏んだ）
