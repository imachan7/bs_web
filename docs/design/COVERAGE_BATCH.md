# 未発火の効果に場面テストを足す手順（coverage 穴埋め）

2026-10-03 時点の進め方。3役（TEST_STRATEGY.md §5）を「未発火の効果エントリ」単位で回す。

## 手順
1. `npm run coverage:effects -- --all > 一時ファイル`。**`--all` を付けないと各節が「…ほか N件」で切れる**
   （10-01〜03 はこの切れた一覧からバッチを作っていて、84件を取りこぼした）
2. 一覧の `カードID 名前 効果ID` 行を拾い、カードごとに効果文と「未発火：効果ID（kind）」を並べたバッチ文書を作る
   （`loadAllCards()` で name/type/colors/cost/family/levels/effect を出す。effects 配列は①に見せない）
3. ①期待値役（Sonnet）に下のテンプレート＋バッチ文書を渡し、新しい part に書かせる。1体あたり15〜20枚
4. 落ちた場面を「実装のバグ」と「解釈の割れ目」に仕分け、割れ目はユーザーに「こう読みました→いいですか」で聞く
5. ②実装役（Sonnet、part 変更禁止・簡略化欄必須）に直させ、メインが定型検証→PR

## 決まっているルール（ユーザー確認済み。迷ったら docs/design/ の手順書を grep で引いてよい）
- 「〜することで、B」は対話中、持ち主に「発動する」を聞く。**聞く前の時点で払えない・B が解決できないなら確認を出さず、何も起きない**（ログに理由つきの「発動しなかった」が出る）。非対話（interactive:false）では払えるなら自動で払う
- 『アタック時』『バトル時』の BP+ で期間が書いていなければバトル終了まで
- 『バトル時』はアタック宣言時とブロック宣言時に発揮する（ブロックされなくても）。「バトル終了時」はブロックされたときだけ
- ブロックを宣言したスピリットは宣言の時点で疲労する
- 【バースト】はセットしてある状態で条件の出来事が起きたら、持ち主に発動を聞く（対話中）。非対話は条件を満たせば発動する
- 「〜1体につき」「〜の数」はこのスピリット自身も数える
- ライフが減るとそのコアはリザーブへ移る（盤面の行に出る）
- 「効果の記述を持たないスピリットとして扱う」は数え方が変わるだけで、効果は発揮し続ける
- 破壊されたスピリットは、破壊時の誘発を処理し終えるまで破壊待機状態でフィールドに残る。【不死】の召喚では、破壊されたスピリットのシンボルも軽減に数える

## 書くもの
効果節ごとに「起きる場面」と「起きない場面（条件を1つ外す・払えない・相手側）」。対話の場面では確認の回数も assert する。
下の「ファイルの割り当て」の part に書き、末尾に `console.log("すべてのチェックに合格しました 🎉（partN）")`。
写像に無いもの（期間つき効果がターン終了まで残るか等）で判定が要るなら、写像の範囲で次のステップの結果（BP・ライフの増減）として観察する。scenario.ts は変更しない。

## このバッチの目的
下のカードの「未発火」と書いたエントリは、今ある smoke が一度も発火させていない効果。**その効果を担う節**（効果文のどの節かは自分で判断する。kind 名は手がかり：burst＝【バースト】、activated＝フラッシュ等の起動能力、magicNegate＝【氷壁】のようなマジック無効、triggered＝『〜時』、fieldEvent＝「〜したとき」の継続、keyword＝キーワード能力、aura＝継続効果）について、起きる場面と起きない場面を書く。**他の節は書かなくてよい**。
- 1つの節に場面2〜3個で十分（起きる／条件を1つ外す）。全カードを回り切ることを優先する
- 盤面を組むのが難しすぎる節（特殊な前提が多い）は、書かずに「書けなかった節」として理由を報告する
- 【バースト】は `start.me.burst: "カードID"` でセットできる。相手の行動（召喚・アタック・破壊・ライフ減少）を steps で起こす
- 確認を断るには `resolveChoice` に何も渡さない（part463 の `drive` は「発動する」しか押せないので、断る場面は自分で act する）
- Lv を満たさない効果は発揮しない
- 【装甲】など「効果を受けない」スピリットは、その効果の対象にも選べない（使用が拒否される）
- 合体スピリットを置くときはブレイヴを cores:0 で置く（合体時のコアの行き先の曖昧さを避ける）
- 起動能力（フラッシュ等）は activateAbility に効果IDを渡す。効果IDが分からなければメインに質問する（推測した ID で書かない）
