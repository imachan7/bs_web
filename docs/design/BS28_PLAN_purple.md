- 同じ文面は前の弾の表と読みをそろえた：【毒刃：N】＝BS27_PLAN_purple（010-1・015-1）、召喚条件＝BS27-051-1・052-1（A1・A4・A6）、Uトリガー＝BS25_PLAN_purple 054-3・X04-2 と BS26-X01、【トリガーカウンター】の窓＝BS26_PLAN_purple、バーストの「かわりに」「その後コストを支払うことで」＝BS27-078-1・BS25-079-1・BS24-009-1（赤）、【呪滅撃】＝BS24-X02-1。BS28_PLAN_red はまだ無い
- 全カード共通：「スピリット」を対象・範囲・数にする節はアルティメットに当たらない（ULTIMATE_PLAN B1・B7）。「スピリット/アルティメット」と書かれた節だけ当たる。アルティメットの効果も「相手の効果」（B10）。各行の「動かない」に当てはめた
- **【毒刃：N】の読み（012・017 で共通。BS27 の表と同じ）**：『このスピリットのバトル時』（アタック側・ブロック側のどちらでも。解決順はターンプレイヤーが選ぶ）に、相手のデッキの上から N 枚を裏向きで相手のスピリット/アルティメットの下に置く。置き先は相手のスピリット/アルティメットから置く側が好きなように割り振る（Q20425）。デッキが N 枚に満たなければある分だけ。置き先がいなければ置かない。デッキ破棄ではない（ULTIMATE_PLAN C2 と同じ扱いと読んだ）。下のカードはそのスピリット/アルティメットが場を離れるとき持ち主のトラッシュへ破棄する（既存 `trashUnderCards`）
- **【毒刃】を「発揮させる」読み（017-1・074-3 で共通）**：効果で【毒刃】を発揮させるときは、『このスピリットのバトル時』を待たず、その場で【毒刃：N】の置く処理（上の読み）だけを行う。バトルしている必要は無い（Q5017：自分の召喚直後の自分の【毒刃】も発揮させられる）。発揮させる対象のスピリットがそのときのLvで【毒刃】を持たなければ何も起きない（Lv が足りない・持たない）。置き先の割り振りは【毒刃】を発揮させた側が行う**読み**
- **軽減シンボル「極」（018・075・X04）**：staging の reduction に `ultimate` が出る。ULTIMATE.md §1.2・§5：[極] の軽減シンボルは**自分の場のアルティメットの極シンボル1つにつき1軽減**。色（紫など）のシンボルでは軽減できず、逆に極シンボルは色の軽減（紫など）に使えない（B11・Q22588 の BS25-064-1 と同じ向き）。「色とシンボルを無色として扱う」効果が発揮中でも極として使える（ULTIMATE.md §1.2）。アルティメットが場にいなければ [極] ぶんは軽減されず、残りの色の軽減だけが効く。各カードの先頭に軽減の行を置いた（表の1行を1節と数えない特別行）。BS28_PLAN_red ができたら赤のカードと読みを合わせる
- **下にあるカードの枚数の数え方（011・012・015・017 が置く側、010・015 が数える側）**：いま置かれている裏向きのカードの枚数。煌臨元は数えない（Q1050）。アルティメットにも置かれる

## 確かめたいこと

- **015-2** 「カードが2枚以上、下にある相手のスピリット/アルティメットすべての効果は発揮されない」の「効果」に、アルティメットの【Uトリガー】（発揮のタイミングが『アタック時』などのもの）も含めて止まる、と読んだ。含めないとすると、下に2枚以上あるアルティメットでも相手のアタックステップ中の Uトリガーは行われる（Q&A は【装甲】で防げるとだけ）
- **013-1** 「相手の合体スピリット1体のブレイヴすべてを破壊する」で、ホスト（スピリット）が【装甲：紫】などで効果を受けないとき、そのブレイヴも破壊できないと読み、そのスピリットを選べないと置いた。ブレイヴ側の耐性だけで見る読みだと、ホストが【装甲】でも合体したブレイヴが【装甲】を持たなければ破壊できる
- **010-2** 「相手の効果で破壊されず、手札/デッキに戻らない」の「相手の効果で」を、破壊と戻すの両方にかかると読んだ（BS27-013-1 と同じ）。戻す方は相手以外の効果（自分の効果）でも止める読みだと、自分のコストの戻しも止まる
- **074-3** 074-2 のバースト経由でフラッシュ効果を発揮するときは、メインステップ中でも発揮できる（「この効果は、メインステップで使えない」は使うときの制限）と読んだ。バースト経由でもメインステップでは発揮できないとすると、自分のメインステップ中にライフが減ったとき（自分の効果でライフのコアを動かしたとき）に発揮できない
- **075-2** 「自分のスピリット2体を破壊することで、相手は、相手のアルティメット1体を破壊する」を、コストは自分のスピリット2体の破壊だけで、相手にアルティメットがいなくても使えると読んだ（Q25351 が「アルティメットを破壊しなくても075-3 は行える」と読めるため）。COST_MODEL の「A も B も完全に解決できるときだけ」に従うと、相手にアルティメットがいないとき使えなくなり、075-3（バーストをセットしているときの破壊）も使えない
- **X04-4** 「この効果でスピリットを破壊したら」の「破壊したら」に、【呪滅撃】などで破壊されず場に残ったときを含めない（実際に破壊が成立したときだけ）と読んだ。含めるとすると、破壊が防がれても（【装甲】でなく【呪滅撃】で残ったとき）ライフのコアが置かれる
- **056-2** 056-2 の「このアルティメットカードを召喚する」の召喚条件を、先に召喚した魔影のスピリットが紫ならその召喚後の盤面で見る（召喚する直前に見る）と読んだ。バースト発動の時点（魔影の召喚前）で見る読みだと、紫のスピリットがいない盤面では召喚できない
- **011-1** 「かわりに、相手のスピリット/アルティメット1体を疲労させる」のバーストのセット判定を、解決時（疲労させる直前）に見ると読んだ。このスピリットの破壊の時点（誘発時）で見る読みだと、破壊の間にバーストをセットしても候補が変わらない
