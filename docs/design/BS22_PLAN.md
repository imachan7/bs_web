# BS22 実装計画（剣刃編 第4弾：暗黒刃翼）

データは `data/staging/BS22.json`（2026-11-06 取り込み。`python3 scripts/fetch_wiki_cards.py --set BS22 --refer '剣刃編 第4弾：暗黒刃翼' --pages 2 --out data/staging/BS22.json`）。番号の抜け・重複なし。
**対象は99枚**（X13 はキャンペーンで追加されたカード）：BS22-001〜084・X01〜X08（スピリット・ブレイヴ・マジック・ネクサス。多色は 070 白紫・071 黄赤）と、一覧に混ざっている X13-01〜06・09 の7枚。SD11-X02 は既存なので飛ばす。
新しいキーワードは【分身】（024・X03・069・077）。ほかは既存（【連鎖】【強化】【重装甲】【聖命】【激突】【神速】【強襲】【大粉砕】【自分のライフ減少後】）。調査メモは `BS22_SURVEY_<色>.md` と `BS22_SURVEY_bunshin.md`。
進め方は BS21 と同じ（調査役 → 確認 → 期待値役 → 実装役 → データ役 → `merge-set.ts`）。Mistral の枠は尽きているので、サブは Claude（期待値・実装＝Sonnet、データ＝Haiku）。

## 2. 確認したもの（2026-11-07 ユーザー確認）

| # | カード・節 | 決まったこと |
| :-- | :-- | :-- |
| 0 | X13-01〜06・09 | 入れる（キャンペーンで追加されたカード） |
| 1 | 【分身：N】の枚数 | 「N枚まで」なので 0〜N枚を出す側が選ぶ。デッキが足りなければある分だけ |
| 2 | 【分身】で置くコア | 1体ずつ、1個以上の個数を出す側が選ぶ。リザーブが空なら出せない |
| 3 | 分身の除外・破壊後バーストが見る情報 | プールに「除外」の効果も、破壊されたスピリットの属性を見るバーストも無いので決めない（入るときに決める） |
