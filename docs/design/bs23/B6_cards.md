## BS23-038 冒険天使チャール
- 種類 spirit / 色 yellow / コスト 3 / 軽減 ['yellow'] / 系統 ['天霊'] / シンボル ['yellow'] / Lv [{'level': 1, 'cores': 1, 'bp': 2000}, {'level': 2, 'cores': 2, 'bp': 3000}, {'level': 3, 'cores': 3, 'bp': 4000}]

```

自分の手札にある黄のブレイヴカード3枚までをオープンして手元に置くことで、オープンしたブレイヴカード1枚につき、自分はデッキから1枚ドローする。
```
