- 種類 nexus / 色 blue / コスト 4 / 軽減 ['blue', 'blue'] / 系統 [] / シンボル ['blue'] / Lv [{'level': 1, 'cores': 0, 'bp': 0}, {'level': 2, 'cores': 5, 'bp': 0}]

```
このカードには配置時を含め、このネクサスの効果以外でコアを置けない。
Lv1･Lv2
系統：「剣刃」を持つ自分のブレイヴがコストを支払って召喚されたとき、ボイドからコア1個をこのネクサスに置く。

```
