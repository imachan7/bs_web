# 耐性の総当たり（`npm run audit:immunity`）

バグ探しの②（2026-11-03 着手）。「耐性を見ていない」種類のバグは、実装の途中で気づいて直してきたものが大半だった。
全カードの効果を、**相手が耐性を持った盤面で**発火させ、相手の盤面が変わったものを洗い出す。

## 1. 作り

- 発火の仕組みは part190（全効果エントリの火入れ）と同じものを使う。盤面作りと発火を `scripts/smoke/fireAll.ts` に切り出し、part190 と監査の両方が使う（part190 の挙動は変えない）。
- 相手（p2）に、総当たりの中だけで使う「盾」のネクサス（`AUDIT-SHIELD`。`CARD_DB` に登録する）を置く。効果は次の4つ：
  - `constraintGrant` ownAll → `immuneToOpponentEffects`（`against` 省略）：自分のスピリットは相手のスピリット・マジックの効果を受けない
  - `globalConstraint` `handImmuneForPid`（`includeNexus`）：手札
  - `globalConstraint` `lifeImmuneForPid`：ライフ
  - `globalConstraint` `noDeckMillByOpponent`：デッキの破棄
- 発火の1回ごとに、p2 の盤面を前後で写して比べる。見る所：スピリット（場所・コア・疲労・BP・Lv）・手札・ライフ・デッキ枚数・トラッシュのカード。
- 変わったら「カード・エントリ・発火の種類（誘発名／ステップ／マジック）・変わった所」を1行で出す。定型には入れない（誤検出を含むので人が読む）。

## 2. 正しく変わるもの（誤検出として仕分ける）

- 発生源がネクサスの効果によるスピリットの変化（`immuneToOpponentEffects` はネクサスの効果を防がない＝カードの文言どおり）
- p2 のリザーブ・トラッシュのコア、p2 のネクサス（守っていない）
- p2 自身の効果による変化（発火で p2 の誘発が起きた場合）
- 盾が取り除かれた後の発火（その回は無効として数える）
- 「相手は、相手の〜する」（相手が実行する効果）が耐性に止められるかは**ルールの確認が要る**。出たら一覧にしてユーザーに聞く

## 3. 検出の確かめ

既知のバグを戻して出ることを確かめる：EFFECT_GATE 5i で直した「`randomOpponentHandMagicDiscard` が `handImmuneFor` を見ない」を一時的に戻し、そのカードが一覧に出ることを見る。
