| 起動の使用枠：アタックのかわりに使う（BSC16 の表の部品） | 既存の起動能力にはアタックの権利を消費する枠・条件が無い | 004-2・006-2・010-2・012-2 |
| 誘発：「手札にあるこのカードの誘発」（他のカードの破壊を拾って手札から召喚できる） | 既存の手札からの発動は【神速】など使用宣言型で、フィールドの出来事を拾わない | 026-2 |
| 条件の軸：バトルしている相手がアルティメット | 既存のバトル中の条件に相手の種類の絞り込みが無ければ足す（確かめてから） | 028-2 |
| 組み合わせ方：「戻したものとして扱う」（【オンステージ】の戻す処理の置き換え）と、タイミング「【オンステージ】を発揮したとき」 | 戻す処理は効果の引数で、誘発から書き換える軸が無い（引数で運ぶ） | 039-1 |
| 制約：「このカードにはこの効果以外でコアを置けない」 | コアの置き先のカード自身を限定する制約が既存に無い | 040-1 |
| タイミング：「【マイユニット】を発揮したとき」（並べたときとは別の出来事） | 並べる出来事ではなく、使った（後半まで解決した）ことを拾う誘発が無い | 040-2 |
| アクション：使い終えたマジックを自分のフィールドに置く | 使い終えたマジックの行き先はトラッシュ（と【光芒】の手札）だけで、フィールドに置く行き先が無い | 042-3・043-3・044-3 |
| 数え方の軸：体数を数えるとき自身を2体と数える（「1体につき」には効かない） | 既存の体数判定は1体ずつで、重み付けの軸が無い | CP14X21-1・CP14X22-2・CP14X21-2 |
| 制約：「自分のバーストは破棄されない」 | 既存の破棄されない制約はデッキ・手札で、バーストエリアのカードを守る軸が無い | CP14X22-3 |

## 確かめたいこと

- **001-2** 【マイユニット：N】の定義の本文（batspi「カードの効果 汎用編【マイユニット】編」）が取れなかったので、効果文と Q&A から「並べるのは並び順を動かすだけで、並べられたスピリットの状態（回復）・コア・Lv は変わらない。並べる側はアタック中の疲労したこのスピリット自身を含まない」と読んだ。並べられたスピリットが疲労するなら、これらのスピリットがこのターンのアタックで使えなくなり、002-2 などのテストが変わる。並べられたスピリットの左右の意味（右隣・両隣の左右の分け方）にも影響しうる
- **001-3** 「【マイユニット】で「ラビィ・ダーリン」を並べたとき」：『アタック時』の別の効果ではなく、【マイユニット】の並べるという出来事で誘発する誘発（001-2 の解決後に解決）と読んだ。『アタック時』の同時の列に並ぶ別の効果なら、ターンプレイヤーが「並べたとき」の効果を先に解決すると条件を満たせない場面ができる（001-3・002-3 のテストが変わる）
- **001-3** 「ブロックされない」「このバトルの間」の期間：期間が書かれていない 001-3・002-3・022-3 は、そのアタックの間と読んだ（BSC16 032-2 と同じ）。そのターンの間なら同じターンの2回目のアタックにも効く
- **005-3** 「“『このスピリットのアタック時』相手はバーストを発動できない”を与える」：与えられたスピリットがアタックしたとき、相手がそのアタックが終わるまでバーストを発動できない、と読んだ。アタック時の効果の解決の間だけなら、ブロック後のバーストが発動できるかが変わる
- **006-3** 「アタックしている自分のスピリットは、相手のスピリット1体を指定し、そのスピリットにアタックできる」：すでに指定アタックのアタッカーでも、この効果で指定先を変えられる（変更する扱い）と読んだ。変えられないなら、指定アタックの手本カード（BS01-037）と同時に使う盤面は不発になる
- **007-2** 「【アブソリューツ】を持つ自分のスピリットが【オンステージ】で召喚されたとき」：Q11571 に従い、このスピリット自身を召喚したときは発揮しないと読んだ。BSC16 004-2（自身の召喚に反応する）の読みと食い違うので、BSC16 004-2 も自身を除くか、004-2 だけ自身を含むかを決めたい
- **008-3** 「破壊されたスピリットよりコストの低いスピリットカード」：同時に複数の詩姫が破壊されても誘発は1回（CONFIRMED_RULES §1）。そのとき基準にするスピリットを持ち主が選ぶと読んだ。基準の決め方が別（最もコストの高いもの等）なら召喚できるカードの範囲が変わる
- **015-2** 「両隣に並べる」：どの詩姫を左右のどちらに置くかは持ち主が選ぶと読んだ。右隣に置けなければ（フィールドの端など）並べ方に制限があるかを確認したい
- **015-3** 「コスト6以上」：今のコスト（増減込み）で見ると読んだ（BSC16 007-3 と同じ読み）。印刷コストなら、コストを増減する効果が働いている盤面のテストが変わる
- **024-2** 「黄のシンボル1つにつき、…オープンできる」：オープンする枚数は 0 から黄のシンボル数までの範囲で持ち主が決める（「N枚まで」型）と読んだ。シンボルの数ちょうどをオープンするかしないかの2択なら、枚数を選ぶテストが変わる
- **026-2** 召喚するとき、破壊待機のスピリットのコアは使えない（リザーブのコアで払う）と読んだ。使えるなら、リザーブが足りないときに高い Lv で召喚できる盤面が変わる
- **028-3** 「召喚し、このスピリットをデッキの下に戻す」は同時で、このスピリットのコアは戻す待機のまま召喚に使えない（リザーブのコアで払う）と読んだ。召喚が先でこのスピリットのコアも使えるなら、召喚するスピリットを高い Lv で出せる盤面が増える
- **032-3** 「【歌】を持つマジックカードが自分のフィールドにある間、BPを比べ破壊した相手のスピリットのコアすべてはボイドに置かれる」：このバトルの間かつ【歌】のマジックがある間と読んだ。そのターンの間なら、同じターンの2回目のアタックにも効く
- **033-2** 「その対象すべてを疲労状態でフィールドに残せる」：確認は1回で、同時に破壊されたコスト3以下を全員まとめて残すか残さないかと読んだ。1体ずつ残すかを選べるなら、一部だけ残す盤面ができる
- **034-2** 対象の相手がいなくてもライフ3以下なら召喚だけ行うと読んだ（「この効果発揮後」は A を発揮すれば不完全でも B へ進む。CONFIRMED_RULES §4）。対象がいないと発揮したことにならず召喚もしないなら、召喚の盤面が変わる
- **035-3** 「ターンで初めてBP0になったとき」：035-2 の BP-10000 で BP0 になり、かつそのターンにそのスピリットが初めて BP0 になったときだけ召喚できると読んだ（Q19632）。そのターンにすでに BP0 になったものは数えない
- **039-1** 「【オンステージ】を発揮した自分のスピリット1体をデッキの下に戻したものとして扱う」：実際にはデッキに戻さずフィールドに残し、【オンステージ】の後半（召喚・ドロー）は戻したものとして解決すると読んだ。残ったスピリットはそのターン、アタックのかわりに使ったのでアタックできないとした。実際にデッキの下に戻る（発揮した扱いだけ変わる）なら、このネクサスを疲労させる意味が変わる
- **042-3** 「その後、このマジックカードを自分のフィールドに置くことができる」：バトル終了時の効果を解決し終えたあとに置くと読んだ（使った直後ではない）。使った直後に置くなら、そのバトルの間も【歌】のマジックが自分のフィールドにある（027-2・030-3・032-2 の条件を満たす）盤面が変わる
- **X02-4** 「相手は、ブレイヴをスピリット状態にできない」：召喚時の選択に加えて、ホストが消えて分離したブレイヴがスピリット状態で残ることも止めると読んだ。召喚の選択だけを止めるなら、分離で残るブレイヴの盤面が変わる
