- **合体時・合体条件とアルティメット**：ブレイヴは合体条件にアルティメットと書かれたものだけがアルティメットに合体できる（ULTIMATE_PLAN B13・Q358・Q360）。この弾の紫のブレイヴ2枚（062・063）の合体条件は「【毒刃】を持つ」「コスト4以上」でアルティメットとは書かれていないので、**アルティメットには合体しない**。スピリットの【合体時】【合体中】の節は、ブレイヴが合体している間のそのスピリット（ホスト）自身の効果で、アルティメットには当たらない（016・062・063 の各行に書いた）
- **【毒刃：N】の読み（010・011・015・X01 で共通）**：『このスピリットのバトル時』（アタック側・ブロック側のどちらでも。TIMING_CHART ＞1〜2B の同時の列に入り、解決順はターンプレイヤーが選ぶ）に、相手のデッキの上から N 枚を**裏向き**で相手のスピリット/アルティメットの下に置く。置く先は、バトルしている相手に限らず、相手のスピリット/アルティメットから、置く側（毒刃を持つスピリットの持ち主）が好きなように割り振る（Q20425：「好きなように割り振って」）。デッキが N 枚に満たなければある分だけ。相手に置き先がいなければ置かない（デッキはそのまま）。置かれたカードはデッキ破棄ではない（相手のデッキ破棄無効に影響されない・「破棄されたとき」の誘発は出ない。ULTIMATE_PLAN C2 の Uトリガーと同じ扱いと読んだ）。下のカードは、そのスピリット/アルティメットが場を離れるとき（破壊・消滅・手札/デッキへ戻す・除外のどれでも）持ち主のトラッシュへ破棄する（既存 `trashUnderCards`）。裏向きなので置いた側の相手には中身が見えない（`forView` が下のカードを隠す先例）

## 確かめたいこと

- **010-1** 【毒刃】の置き先の読み：置く側が、バトルしている相手に限らず、相手のスピリット/アルティメットから好きに割り振る（Q20425）。汎用編【毒刃】編の本文は読めていない。違う（バトルしている相手にだけ置く、など）と、毒刃のカード4枚と 062-4 の置き先が変わる
- **009-1・051-2** Q4923 の「ガードされる」を、ULTIMATE_PLAN C3 の「ヒットしない」の意味と読み、C4 のガード（サーベルセセリなどが置かれたとき）とは区別して、051-2「自分のUトリガーがガードされたとき」はコストが高くてヒットしなかっただけでは発揮しない。BS26-X01-2 と同じ読み。ヒットしなかったときも「ガードされた」とするなら、051-2 がヒットしないたびに発揮する
- **013-2** コアを置く支払いでそのスピリットのコアが0個になる（最後の1個）とき、宣言が通るのか。読みは「払えれば宣言は通り、消滅はそのあと」。違うと、コア1個の相手はアタック/ブロックできないことになる
- **078-2** 破壊したスピリット/アルティメットの下のカードを他の1体の下に移す順：「場を離れるとき下のカードは破棄」と衝突するので、破壊と同時に先に移す読み（Q25334・Q25335）。他に置き先がいなければ破棄になる。違うと、すべて破棄で移動が成り立たない
- **071-2** 「相手が、相手のスピリット/アルティメットを消滅させたとき」の「相手が」を、相手自身の行動・効果によるものと読み、自分（ネクサスの持ち主）の効果での消滅と維持コア割れの自然な消滅は含めない。違うと、自分の効果で消滅させても相手が手札を捨てる
