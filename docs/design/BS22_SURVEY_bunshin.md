対象カード（効果文は staging/BS22.json）：024 ジョーニン・トンビ（Lv1・2【分身：1】『相手によるこのスピリットの破壊時』）／X03 レックウマル（Lv1〜3【分身：2】『召喚時』）／069 光牙の忍び里（「自分の分身スピリットすべてBP+2000」、Lv2「自分の分身スピリットがいる間…効果を受けない」）／077 シャイニングシャドウ（「この効果発揮後、自分の[レックウマル]がいるとき、1体の【分身：2】を発揮させる」）。

汎用編「分身」（Q782〜Q793、2024/10/31 更新）
- 本則：【分身：N】はデッキの上からN枚までを裏向きでフィールドに置き、リザーブのコア1個以上を置く。置いたカードは緑の分身スピリット（コスト0・Lv1・BP3000・系統「分身」）になる。**召喚ではない**。コアはリザーブから置く（【神速】と同じ扱い）。
- Q782 キーワードの概要。
- Q783 N は一度に置ける分身スピリットの最大数。
- Q784 分身スピリットは緑のシンボルを持つので、アンブロックでライフを減らせる。
- Q785 スピリットを対象にする効果の対象になる。ブレイヴとは合体できない。
- Q786 テキストの無いスピリットとして扱う。
- Q787 破壊されたとき、破壊で誘発した効果を解決してから**表向きでトラッシュ**へ。スピリットカードでなくても『破壊後』バーストは発動できる。
- Q788 手札・デッキ・手元には戻らず、トラッシュ（表向き）へ行く。
- Q789 召喚ではないので、「召喚時にコアが置かれる」類の効果は働かない。
- Q790 持ち主は中身を確認できる（相手に見せずに）。
- Q791 手札に戻らずトラッシュへ行くので、入れ替えはできない。
- Q792 実際にフィールドを離れるときに、保留中の効果が済んでからトラッシュへ。
- Q793 別々の効果で置かれた裏向きスピリットは、それぞれ中身を保つ。区別できるよう別の場所に置く。
- 消滅も破壊と同様にトラッシュ（スピリットとして）へ行く。

カード別Q&A
- 024：Q4364（強化）・Q4365（分身）は汎用編を参照。**Q4366**：悪の滑空手…の召喚時効果で解決される『このスピリットの破壊時』では、024 の『相手によるこのスピリットの破壊時』の分身は**発揮できない**（「破壊時」と「相手による破壊時」は別のタイミング）。
- X03：Q4437（分身）・Q4438（強化）は汎用編を参照。Q4439：Lv2・3の【強化】で自身のLv3効果の疲労体数も+1体される。
- 069：Q22526 は汎用編参照のみ。
- 077：Q25214 は汎用編参照のみ。**Q25215**：077 で分身を発揮させたとき、相手の「召喚時」効果の解決後にバーストを発動できる。

## 4. 入れ方の候補
A. **個体に上書きを持たせる**：`CardInstance` に `bunshin?: { cardId: string }`（元のカード）を持たせ、`card()` 経由でない属性読み（`instColors`、BP/Lv 表、`getCard(inst.cardId)` の多数）を分岐。触る：cardInstance.ts、level.ts、GameState.ts、removal.ts（トラッシュへ元 cardId）、viewFor。衝突：`getCard(inst.cardId)` が約870箇所にあり、見落とすと元カードの効果・コスト・色がそのまま読まれる（分身が元カードの効果を発揮してしまう）。
B. **分身用の仮のカード定義を作る**：cardId を `BUNSHIN-T001` のようなトークン形式にして CARD_DB に1件（緑・Lv1・BP3000・系統分身・効果なし）。個体は `instance.cardId = 仮ID`、元カードは別フィールド（`bunshinOrigin: string`）に持つ。`isTokenCard` が手札・デッキ・トラッシュ行きを止めるので、「戻る時は破棄」は自然に出るが、**破壊時は元カードをトラッシュに入れる**分岐が removal.ts:616-636 に要る。衝突：トークンは破壊後バーストを積まない（Q787 は発動できると言う）ので別扱いが要る。`isTokenCard` 判定箇所（removal.ts 4か所・deckPolicy・token.ts）。
C. **`underCards` 的に「裏向きの元カード」を持つ**：個体の cardId は仮定義（B）、元カードは `underCards` に似た非公開の枠（`faceDownCard`）。viewFor で相手には隠す（forView:716 を流用）。B と組み合わせる形で、隠し方の先例（underCards、BS19-X02）を使える。

## 5. 資料から決められない点（読みが2通り以上）
1. 破壊後バーストの材料（色・コスト・系統）は、分身スピリットのもの（緑・コスト0・分身）か元カードのものか。Q787 は「スピリットカードでなくても発動可」とだけ書く。引いた語：「破壊後」「バースト」→当たり（Q787）だが材料は不明。
2. 分身スピリットの名前の扱い（「名前なし」か、元カードの名前か。ログ・名前指定の効果）。引いた語：名前→要約のみ。
3. デッキが N 枚に足りないとき・0枚のとき、リザーブのコアが0個のとき（コスト扱いで不発か）。引いた語：デッキ・足りない・コア→当たりなし。
4. コア配置：1個以上の上限と、複数体に分ける配分は誰が決めるか。引いた語：1個以上→当たりなし。
5. 077：「【分身：2】を発揮させる」は X03 の分身部分だけを発揮し、Lv の条件は X03 の現在 Lv で見るか。召喚時トリガー（『このスピリットの召喚時』）の条件は無視してよいのか。引いた語：発揮させる→Q25215 のみ。
6. 024 の『相手によるこのスピリットの破壊時』に置いた分身は、破壊待機中の 024 とともに場にいる。この間の分身の扱い（体数・アタック不可か）は資料に無し。
7. 除外される場合の行き先（トラッシュか消えるか）。引いた語：除外→当たりなし。
8. 069「自分の分身スピリット」の判定は系統「分身」か、分身の由来の印か。引いた語：参照→当たりなし。
9. 合体の範囲：分身スピリットが「ブレイヴを合体させる側（ホスト）」になれるか。Q785 は「ブレイヴとは合体できない」とのみ。
10. 元カードのトラッシュでの向きと、相手から見えるタイミング（Q787 は表向きとする。X03 のような元カード名をトラッシュで公開か）。上の表では表向きと読んだが、要約の表現に依存。
