## 2. 解釈

### 2.1 Q&A で決まるもの（batspi「連鎖」「強化」。確認不要）

**【連鎖】**
- 書式は「【連鎖：条件《X シンボル》】」の行と「[X]：〜」の行。上に書かれた効果（連鎖元）に**続けて**発揮する。同時ではないが、連鎖元から派生した破壊時効果などより先に解決する（Q772）
- 連鎖元の発揮タイミングであれば、連鎖元が解決できなくても（対象なし等）条件を満たせば発揮する（Q773）。連鎖元が発揮されない（タイミング自体が来ない・効果が止められている）なら連鎖も発揮しない（Q776。連鎖は連鎖元と一体の効果）
- 条件は**自分のシンボル**（場のスピリット／ネクサス／合体スピリットのブレイヴ）。判定は連鎖を発揮するとき。連鎖元と連鎖の発揮タイミングが違う場合は、連鎖元を発揮した時点で条件があれば、後でシンボルが無くなっても発揮する（裁定4・ウィンドウォール）
- 期間の書かれていない継続の連鎖（「〜すべてはブロックできない」等）は、条件を失った瞬間に止まり、満たした瞬間に効く（Q777・Q778）
- 「【連鎖：[青][青]】」は青2つ。2色の条件はそれぞれ1つ以上。別の色として扱えるシンボル1つで2色ぶんは満たせない（Q781）
- 同じタイミングの連鎖が2つあれば、使ったプレイヤーが順番を選ぶ（Q779）
- **「【連鎖】を持つスピリット」**は、連鎖を含む効果を発揮できるLvにいるスピリット。シンボルが足りなくても持っている（Q774・Q775）
- マジックの連鎖は、マジックの効果を発揮するときに条件を確かめる（Q780）

**【強化】**（色ごとに1種。同じ記述の【強化】は重なる。1体が2つ持てる。一部だけ発揮は不可：Q754・Q755）
- 赤：自分の「BP破壊効果」の上限 +1000。**数値で書かれた上限だけ**（「同じBP」「BP以下」には効かない：Q756）。バースト効果にも効く（Q758）
- 紫：自分の「コア除去効果」でリザーブに置くコア +1個。ライフのコアには効かない（Q759）。「すべてのコアを1個ずつ」は1体からだけ追加で1個（Q760）。「1個残して残りすべて」には効かない（Q761）。行き先がリザーブ以外になった除去には効かない（Q765）
- 緑：自分の「相手への疲労効果」の体数 +1体（重疲労も含む：Q770）
- 白：自分の「スピリット回復効果」の体数 +1体。「このスピリットを回復」には効かない（Q762）
- 黄：自分の「BP-効果」を -1000。「Lv1のBPを2000として扱う」は BP-効果ではない（Q763）
- 青：自分の「相手へのデッキ破棄効果」の枚数 +1枚。実際に破棄する最終の枚数に足す。【粉砕】にも効く（Q757・Q764）。0枚のときは足さない（Q766）。上限のある破棄は上限を超えない
- 数値は効果を解決するときの最終の値に足す（紫・緑・白・青）。追加の対象は強化元の効果の記述（対象の条件）に従う
- 独立した効果それぞれに足す。「〜することで〜する」は強化後の数値で発揮できなければ全体を発揮しない
- **カードの色ではなく効果の種類で効く**。既存の弾のカードの効果（マジック・ブレイヴ・ネクサス・バーストも）にも効く

### 2.15 連鎖の確認（2026-11-01 ユーザー確認）
- 連鎖元が「〜できる」で、**断っても連鎖は発揮する**（BS19-025。発揮タイミングが来ていれば Q773）
- 【神速】の下の連鎖（BS19-024）は、**【神速】で召喚したときだけ**発揮する。メインステップの通常の召喚では発揮しない（連鎖は連鎖元と一体。Q776）
- 期間の書かれていない『アタック時』の連鎖「このスピリットは最高Lvとして扱う」（025）は、そのバトルの間
- X02 の「相手によって破壊される/手札かデッキに戻るとき」は破壊と戻るの両方にかかり、バトルの BP 比較での破壊も含む（BS12_PLAN の 09-07 確認）

### 2.2 こう読んだ（2026-11-01 ユーザー確認。指摘のあった行は「確定」に直した。ほかは表の読みのまま）

**仕組み**
- A【連鎖】：連鎖元の action を `sequence` の先頭に、連鎖を `if`（`count: { ownColorSymbols: 色 }, atLeast: N`）で後ろに置く。新しい器は要らない。連鎖元が不発でも連鎖は解決する（Q773）。継続の連鎖は aura／constraint の condition に同じ条件。「【連鎖】を持つ」は keyword `rensa` を連鎖を含む効果と同じ Lv に宣言（Q774）
- B【強化】：continuous の kind 1つ（色＝効果の種類）。数値を足す所は、主な6つの型（`destroy` の数値の bpMax／`removeCores` のリザーブ行き／相手への `exhaust`／自身以外の `refresh`／`bpMinus`／相手の `discard from deck` と【粉砕】）。1枚専用の型で該当しそうなものは洗い出して、1つずつ対応する。既存の弾のカードにも効く
- C 場に残るマジック（099・100・103・110・112）：フィールドに新しい置き場を作る。置いている間は中身の継続効果を出し、破棄の条件で自分のトラッシュへ。**ほかの効果の対象にならない**（このプールに場のマジックを触る効果が無い）。置いている間フラッシュ効果は使えない。同名を2枚置ける（制限の記述が無い）
- D X02（スピリットの下に裏向き）：個体に「下のカード」の一覧を持たせる。非公開・場を離れるとき破棄。下のカード1枚の破棄をコストにできる。アタック時は「破壊し、そのスピリットのコアのうち1個だけボイド、残りはリザーブ」

## 3. 新しい部品

### 3.1 済み（バッチ M1・M2）
- 【連鎖】は新しい器なし（sequence＋if＋`ownColorSymbols`）。`keyword: "rensa"` のラベルで「持つ」。ラベルのキーワードは `spiritHasKeyword` でも拾う（effectGrant の keywordFilter などが【連鎖】を見られるように）。ラベルでも `whileCombined` のものは合体中だけ
- 【強化】は `keywords/kyoka.ts`。自分のスピリットへの疲労・コア除去（`side: "own"`）には足さない。すべてのスピリットから取るコア除去（Q760）は該当カードが無いので未対応
- 付与された【聖命】：`effectGrant.granted.keywordBody`。元から持つ個体には付けず、重なっても1回。**BS11-070 は「持つ」だけで働かなかったので直した**（BS18-070 と同じ2エントリにした）
- `bpMinus` はマジックの使用時に指定した対象を受け取る
