## 1. ⚠️ 実装前に決めることリスト（推測で書かない）

### 1.1 【合体時】効果は**スピリット側のカードにもある**（7枚）— 設計の穴

BRAVE.md §4 は「【合体中】効果は `effectSources()` に相乗りすればタダで動く」としていたが、
**これはブレイヴ側だけの話**だった。実データでは、**ホストになるスピリットのカード**が
【合体時】効果を持つ:

| カード | 【合体時】の中身 |
| :-- | :-- |
| BS10-008 火星神龍アレス・ドラグーン | Lv2『自分のターン終了時』アタックステップとエンドステップを追加で1回ずつ行う |
| BS10-019 土星神龍クロノ・ボロス | Lv2･Lv3『このスピリットの破壊時』お互いコアを合計5個以下にする |
| BS10-029 木星神龍ノブナガード・ゼウシス | Lv2･Lv3『合体アタック時』合体スピリット1体につき相手1体疲労 |
| BS10-058 水星神龍メルクリウス・サーペント | Lv2『合体アタック時』相手の手札1枚を見ないで選ぶ |
| BS10-X04 月光龍ストライク・ジークヴルム | Lv3『相手のアタックステップ』強制アタックの指定 |
| BS10-X05 堕天神龍ヴィーナ・ルシファー | Lv3:フラッシュ『合体アタック時』デッキ破棄→マジックのフラッシュ効果を発揮 |
| X005R 北斗七星龍ジーク・アポロドラゴン | Lv3『アタック時』BP比べ破壊したとき、もう1体破壊 |

発生源は既に `effectSources` にいるので、必要なのは**「合体しているときだけ発揮する」という発揮条件**。
`EffectDef` に新しいゲート（例: `whileCombined?: true`）を足し、`effectActiveAtLevel` と同じ位置で見る形が素直。
**この軸を足すか、足すならどこで見るかを決めてから着手する。**

なお表記は【合体**中**】ではなく【合体**時**】。BRAVE.md の記述も直すこと。

### 1.4 効果による**分離・再合体** ❓

いまのエンジンは「ホストが場を離れるときの分離」しか持たない。

- BS10-027 若武者ウンピョル：『アタック時』バトル終了時、**合体スピリット1体からブレイヴを分離させ、自分のスピリット1体に合体できる**
- BS10-086 巨星望む大樹Lv2：バトル終了時、**分離することで**、そのスピリットを回復させる（分離が**コスト**）

**決めること**：効果で分離したとき、ブレイヴを残すのに Lv1維持コスト以上のコアが要るのか、
それとも効果による分離なので無償で場に残るのか。
（BS10-027 は「分離させて別のスピリットに合体」なので、コアを置く場面が無いように読める）

### 1.5 効果によるブレイヴ召喚 ❓

- X005R：召喚時、手札のブレイヴ1枚をコストなしで召喚できる
- BS10-029：手札のブレイヴを**好きなだけ**コストなしで召喚。ただし『このブレイヴの召喚時』効果は発揮されない
- BS10-096 最後の優勝旗Lv2：自分のスピリット1体を破壊することで、**同じコストの**ブレイヴ1枚をコストなしで召喚

**決めること**：合体先の選択をどこで挟むか（`pendingChoice` か、ダイレクトブレイヴと同じく1リクエストか）。
また「コストを支払わずに召喚」でダイレクトブレイヴにできるのか（＝合体先を選べるのか）、
それともスピリットとして出るだけなのか。

### 1.6 【超覚醒】（BS10-X01 幻羅星龍ガイ・アスラ）→ **2026-08-25 確定・実装済み**

**別枠のキーワードにする**（将来「【超覚醒】を持つ〜」を参照する効果が出うるため）。
ただし「【覚醒】を持つ〜」の参照には**【超覚醒】も引っかかる**（効果文が「覚醒」を含むため）。
逆向きには効かない。

挙動の差は**「この効果でコアを置いたとき、このスピリットは回復する」の1点だけ**。

実装: `Keyword` に `"superAwaken"`、`shared/rules.ts` の `KEYWORD_INCLUDES` で包含関係を持つ。
回復は `GameEngine.refreshOnSuperAwaken`（コアを移した直後に1回だけ）。

このカードは**プール初の Lv4**でもある（既存900枚超で Lv4 は0枚）。

## 2. 判断が要らない（機械的に実装できる）もの

- **「合体スピリット」「合体していないスピリット」「スピリット状態のブレイヴ」の3つの絞り込み軸**。
  それぞれ `braveRefs` の有無 / 同左の否定 / `field.spirits` かつ `type === "brave"` で出せる。
  使うカードが多い（20枚以上）
- **「相手のスピリット/ブレイヴ/ネクサス/マジックの効果」の列挙**（BS10-053・079・095）。
  → 2026-08-25 に「発生源の種別を `"spirit"` に丸めない」と決めた判断の**実データの裏付け**。
  効果文が4種を明示的に並べている以上、`"brave"` は独立した種別でなければならない
- 【不死：コストN】【氷壁：色】【覚醒】「効果の記述を持たない」はいずれも既存プールに前例あり
- BS10-006 ヤシウムは **禁止カードと制限カード<1> の両方**が付いている。
  禁止・制限は基本的に適用しない方針（[DECISIONS] 2026-08-18）なので、そのまま入れてよい
