## 確かめたいこと

- **008-1・CP14X13-2** 「召喚する」とだけ書かれたバースト効果（コストを支払わずに、が書かれていない）を、BURST.md 2026-09-28 の「《2》以降は払う」に従い**コストを払って**召喚と読んだ。BS28 のブロックアイコンはデータに無い。払う読みなら、コストが払えない（リザーブ不足）と召喚されずトラッシュへ。無償なら必ず召喚される（006-1 は「コストを支払わずに」と書いてあるので無償）
- **X03-2** 「このアルティメットに赤のシンボル1つを追加する」の期間を**このターンの間**と読んだ（CP14X01R-2 と同じ。BS24 の確認で未回答）。このアルティメットが場にいる間ずっと残るなら、ターンをまたいでライフを減らす数が増え続ける
- **053-3** 「『このスピリットの召喚時』効果を持つ」を現在の Lv で有効な召喚時の効果と読んだ（Lv2 以上の召喚時効果を持つスピリットが Lv1 のとき、その効果を「持つ」とは数えない）。印刷された効果で見る読みなら、Lv に関係なく候補になる
- **007-1** 「このスピリットのコアは取り除くことができない」は、手動のコア移動（メインステップ）も止めるか。効果だけを止める読みで書いた。手動の移動が止まるなら、フィールドのコア移動の UI でこのスピリットを元にできない
