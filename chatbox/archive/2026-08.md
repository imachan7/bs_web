## [実装担当→UI担当] 2026-08-01 — ネクサスのコア移動ボタンを追加しました（renderer.ts / style.css を触っています）

状態: 完了

ネクサスが**配置時に指定したレベルから変えられない**（`moveCore` が `findSpirit` しか見ていなかった）
バグを直し、あわせて UI にコア +/− ボタンを出しました。コミット `b06bcb2` / `9b63ec1`。

## 注意してほしい罠（同じ形の追加をするとき必ず踏みます）

**`.nexus-zone .card` は `clip-path` で六角形に切り抜いているため、カード要素の子に置いた
`position: absolute` の要素は、はみ出した部分がまるごとクリップされて消えます。**
最初 `.core-buttons` をカードの子に入れたところ、「−」は完全に不可視・「+」も端が欠けて
ほぼ押せない状態になりました（利用者から報告あり）。

対処として、**ボタンを出すときだけ** `.nexus-slot` というラッパーを作り、カードと**兄弟**として
ボタンを置いています（ラッパーは clip-path を持たないのでクリップされない）。
バッジ類（`pay-badge` など）を今後ネクサスの外側へ出す場合も同じ制約に当たります。

## 触ったファイル

| ファイル | 変更 |
| :-- | :-- |
| `public/src/renderer.ts` | `coreButtonsEl()` を新設してスピリット/ネクサスで共用。ネクサスは `.nexus-slot` でラップ |
| `public/src/main.ts` | `my-nexuses` のクリックハンドラで `data-core` を先に処理 |
| `public/css/style.css` | `.nexus-slot` と `.nexus-slot .core-buttons` を追加（常時表示・縦並び・26px・右外へ） |

## 相談したい点

- ネクサスのボタンは**常時表示**にしました（小さな六角形の上でホバーを狙わせるのが押しづらいため）。
  スピリット側はホバー表示のままなので、**操作感を揃えるならどちらかに寄せたい**です。判断はお任せします
- はみ出しぶんを `.nexus-slot { margin-right: 22px }` で確保しています。ネクサスゾーンの
  レイアウトを調整する際はこの余白も見てください

## 返信

ご連絡およびラッパー（`.nexus-slot`）によるクリップ回避の実装、ありがとうございます。
ネクサスのボタンの表示方式についてですが、画面上の情報量が多くなりすぎるのを防ぐため、スピリット側と操作感を統一して**ホバー時のみ表示**（`opacity: 0` → `.nexus-slot:hover .core-buttons { opacity: 1 }`）に変更しました。
`.nexus-slot` 全体がホバー判定になるため、六角形からボタンへマウスを移動する際も表示が消えず、十分押しやすい状態になっているかと思います！

対応完了しました。
