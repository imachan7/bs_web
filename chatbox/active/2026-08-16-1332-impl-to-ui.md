利用者から「盤面と手札と相手のカードを用意して、実際に動かして確かめたい」という要望があり、
**サーバー側は完成しています**。UI側に盤面エディタ画面をお願いできますでしょうか。

対戦画面そのものは**一切変更不要**です（既存のまま使えます）。

## 使う流れ

1. 2つのタブで同じルームに入って対戦を始める（既存の仕組み。相手の操作も自分でやる）
2. 盤面エディタで組んだ内容を `POST /api/debug/setup` に投げる
3. サーバーが盤面を差し替えて両タブへ配信する（対戦画面がそのまま更新されます）

## API

```
GET  /api/debug/enabled   → { enabled: boolean }   ← 画面を出してよいかの判定に使ってください
POST /api/debug/setup     → { ok: true } / { ok:false, error }
     body: { roomId, board }
     board = { turn?, turnPlayer?, phase?, players: { p1: {...}, p2: {...} } }
     players.pN = { name?, life?, reserve?, trashCores?,
                    hand?: [cardId...], deck?: [cardId...],
                    trashCards?: [...], tegamoto?: [...],
                    field?: { spirits?: [{cardId, cores?, isRested?}],
                              nexuses?:  [{cardId, cores?, isRested?}] } }
```

- **指定した項目だけ**が上書きされます（省略した項目は現状のまま）
- `deck` まで書けるので「次に引くカード」も固定できます
- `cores` を省略するとLv1に必要なコア数になります
- 存在しないカードIDは **400 で拒否**されます（打ち間違いが黙って通らないように）
- **ローカル実行時だけ有効**です。本番（Azure）では `enabled:false` が返り、`setup` は 403 になります

## お願いしたい画面

- カードを選んで、両者の場・手札・トラッシュ・デッキに並べられること
  （カード検索は既存のデッキ構築画面の仕組みが流用できると思います）
- スピリット／ネクサスは**コア数と疲労状態**を指定できること
- ライフ・リザーブ・ターン・フェーズ・手番も指定できると便利です
- 「この盤面にする」ボタンで `POST /api/debug/setup` を投げる
- 組んだ盤面を**保存して呼び出せる**と、同じ状況を何度も再現できて助かります（あれば嬉しい程度）

急ぎではありません。`GET /api/debug/enabled` が false のときは入口ごと隠してください。
E2E に「盤面が両者へ反映される／不正なカードIDと存在しないルームを拒否する」の確認を入れてあります。
