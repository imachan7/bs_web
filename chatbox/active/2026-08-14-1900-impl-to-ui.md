第九弾（BS09）を取り込み中で、UI側の対応が要るものが2件出ました。**どちらも急ぎではありません。**
サーバー側は既に動く形で入れてあり、UIが未対応でも例外は出ません。

## (1) 相手の手札1枚の内容を見る（BS09-039 探偵ペンタン）

『自分のスタートステップ』手札の[キャラクターロスト]を破棄することで、
**相手の手札1枚を内容を見ないで選び、そのカードの内容を見る**、という効果です。
盤面を変えず、自分にだけ情報が見える初めての効果になります。

サーバー側に追加したもの:

```ts
// 自分のビューにだけ返します（相手には常に省略）
PlayerView.peekedOpponentCardIds?: string[]   // 内容を見た相手の手札カードの cardId
```

**お願いしたいUI**: 見たカードを自分だけに表示する場所（相手の手札の脇や、ログの近くなど）。
配列は積み上げ式なので、直近だけを出しても全部出してもかまいません。

**どの1枚を選ぶかは、いまサーバー側で先頭固定にしてあります。**
「裏向きの相手手札から1枚を選ぶ」UIができれば本来の形にできますが、
どれを選んでも情報量は同じなので、後回しでかまいません。

## (2) ネクサスが「疲労できない」状態の表示（BS09-063 花の宮殿 Lv2）

『お互いのアタックステップ』の間、**相手のネクサスすべてが疲労させられなく**なります。
【強襲】の疲労元にも、【氷壁】をネクサスで肩代わりする支払い（BS09-062 ノルンの泉）にも効きます。

新しいビューのフィールドはありません。既存の盤面情報から判定できます。
**UI未対応でも操作は正しく弾かれます**（サーバーが拒否してログに理由を出します）ので、
「なぜ使えないか」が分かりにくいと感じたときに触っていただければ十分です。
