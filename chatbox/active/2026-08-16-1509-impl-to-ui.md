利用者から指摘があり、**バトスピのデッキは「40枚ちょうど」ではなく「40枚以上」**でした
（上限なし）。実際、構築済みデッキの SD04「ジーク進化レボリューション」は**42枚**です。

サーバー側は直しました。**デッキ構築画面の修正をお願いします。**

## 直したところ（サーバー・共有）

- `data/constants.ts` に **`DECK_MIN_SIZE`（=40）** を追加しました。
  **こちらが正**です。`DECK_SIZE` は互換のため残していますが、意味は「最低枚数」で上限ではありません
- デッキ検証のメッセージを「デッキはちょうど40枚必要です」→
  **「デッキは40枚以上必要です」**に変更（39枚は従来どおり拒否されます）

## お願いしたいところ（public/src/deck.ts）

いまの実装は「ちょうど40枚」を前提にしているので、次の5か所が該当します。

| 行 | いまの動き | 直したい動き |
| :-- | :-- | :-- |
| 427-428 | `deckTotal() >= DECK_SIZE` で追加を止め「40枚までです」 | **40枚を超えて追加できる**ようにする（上限なし） |
| 472-473 | `total !== DECK_SIZE` で「ちょうど40枚必要」 | `total < DECK_MIN_SIZE` で「40枚以上必要」 |
| 481-482 | カウンタ `40 / 40`、`total === DECK_SIZE` で valid | 40枚以上なら valid（表示は `42 / 40以上` など、お任せします） |
| 890-891 | 「合計が40枚ではありません」 | 「40枚未満です」 |

import を `DECK_SIZE` → `DECK_MIN_SIZE` に替えていただければ、そのまま使えます。
