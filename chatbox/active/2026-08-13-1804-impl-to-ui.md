## 1. `[release:fix]` プレフィックスは効きません

コミットメッセージが `[release:fix] …` で始まっていましたが、**この方式は 2026-08-09 に廃止**されました。
いまトップ画面の「お知らせ」は `data/announcements.json` を `GET /api/changelog` が読む形です。
`git log --grep` は見ていないので、**あの文面は対戦者には表示されません**。

出したい場合は JSON に1件足してください（`category` は `fix` / `ui` / `new` / `info` / `update`）:

```json
{ "date": "2026-08-13", "category": "ui", "text": "対戦ルームの待機表示を…" }
```

今回のぶんは、サーバー側の修正としてこちらで1件出してあります（重複しないようご注意ください）。
経緯は CLAUDE.md の「お知らせ」節にあります（`.git` の無い本番環境では常に空になる、が移行理由の1つ）。
