「プレイヤーが選ぶべきところをサーバーが自動で決めている」カードが13枚残っています。
サーバー側の選択機構（`pendingChoice`）自体は既にあり、多くのカードで動いています。
**この13枚は選択の器がまだ無いか、UIの表示形が既存と違うものです。**

| カード | 選ばせたいもの | UIの形 |
| :-- | :-- | :-- |
| 王蛇の住処Lv2 | 相手のスピリット1体 | 既存の対象選択でいけるはず |
| 強者統べる大地Lv2 | BP10000以上の自分のスピリット1体 | 同上 |
| ダークスカルデーモン | 相手が選ぶコア1個（**選択者が相手**） | 相手側に選択が出る形 |
| 大風車の丘 | 色をひとつ | 色の選択（6色から1つ） |
| 竜騎集う円卓Lv2 | 手札1枚を破棄して防ぐか | はい/いいえ＋破棄カード選択 |
| 大天使イスフィール | マジックを無償で使うか | はい/いいえ |
| ヒナペンタン | 疲労させるか／効果を出すか | 2つの任意発動の組み合わせ |
| 封印された魔導書Lv1 | 対象を相手のみ/自分のみ | 2択 |
| 魔界七将パンデミウムLv3 | 破棄する手札5枚 | **複数枚選択**（既存は1枚選択のみ） |
| セカンドサイト | デッキ上3枚を戻す順番 | **並べ替え**（新しい形） |
| 颶風高原Lv2 | デッキの下に戻す順番 | 並べ替え |
| ブリシンガメンの首飾り | デッキの上に戻す3体の順番 | 並べ替え |
| 常闇の聖堂／堕天使ミカファール | コアの支払い元 | 既存のコア割り当てUIの流用 |

## 動作確認用のデッキを2つ用意しました

`data/constants.ts` の `DECK_RECIPES` に追加済みです（どちらも40枚・検証済み）。

- `uitest-yp` 「選択UI検証（黄紫）」
- `uitest-gwr`「選択UI検証（緑白赤）」

**`public/index.html` の `<option>` への追加をお願いします**（こちらは `public/` を触らない運用のため）。
なお、デッキビルダーに保存すれば「カスタム: 〜」としてプルダウンに出るので、
追加前でも動作確認自体はできます。

## 進め方の提案

一度に13枚は重いので、**(1) 既存の対象選択でいける2枚 → (2) はい/いいえ系4枚 →
(3) 複数枚選択 → (4) 並べ替え3枚** の順が良いと思います。
サーバー側の `pendingChoice` に新しい種別（複数枚選択・並べ替え）が要る場合は、
**先に形を決めたいので着手前に相談してください**。こちらで型と検証を用意します。

各カードの現状は `data/card-notes.json`（`status:"simplified"`）に1枚ずつ書いてあります。
