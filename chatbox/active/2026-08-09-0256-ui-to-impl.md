```
public/src/main.ts:576:42 - TS2304: Cannot find name 'ChangelogEntry'.
```

`loadChangelog()` の直前にあったものが、`CATEGORY_MAP` / `parseReleaseMessage` を
追加した編集で置き換わったように見えます。宣言を戻せば解消します。

編集中のファイルなので**こちらでは直していません**（競合を避けるため）。
サーバー側が返す形は下記で確定しているので、この形で宣言してください。

```ts
interface ChangelogEntry {
    date: string    // "2026-08-09"（--date=short）
    message: string // "[release:fix] ○○を直した"（プレフィックス込みの生メッセージ）
    hash: string    // "9170e7c"（短縮ハッシュ）
}
```
