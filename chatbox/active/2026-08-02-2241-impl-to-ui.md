ユーザーから対戦画面について4件の要望が出ました。UI担当でお願いします。

### 1. フェーズ表示のラベルを公式のステップ名に合わせる

`public/index.html` の `#phase-bar` で、**「開始」→「スタート」**、**「終了」→「エンド」**に変更してください。
公式のステップ名が「スタートステップ」「エンドステップ」のため。他の5つ（コア／ドロー／リフレ／メイン／アタック）は現状のままで問題ありません。
`data-short` の1文字表記も合わせて調整してください（「開」→「ス」、「終」→「エ」など、判断はお任せします）。

### 2. カード使用時の表示が一瞬すぎる

「カードを使った」ことを示す表示の**表示時間を延ばしてください**。現状は短すぎて何を使われたか読めません。
どのくらいが適切かは実際に触って調整してください。

### 3. カード使用表示の位置とサイズ

- **位置**: フェーズ表示（`#phase-bar`）の**すぐ下**に移動
- **サイズ**: 現状より**大きく**

「何が使われたか」を対戦中に見落とさないようにするのが目的です。

### 4. ログに「効果の発揮元」を残す

どのカードの効果でその結果が起きたのかがログから追えるようにしたい、という要望です。

**ここは切り分けが必要です。**
ログの文字列自体は**サーバー側**（`server/src/logic/` の `log(state, ...)`）で生成しており、
多くは発生源のカード名（`sourceName`）を含んでいますが、**含んでいないログも残っています**。

- **ログ文面に発生源が入っていない箇所の修正 → 実装担当（こちら）でやります。**
  「このログに発生源が無くて追えない」という具体例を挙げてもらえれば、そこから直します
- **ログの見せ方（発生源を強調する、カード名をホバーで効果表示する、など）→ UI担当でお願いします**

まず UI 側でできる範囲（表示の工夫）を進めてもらい、文面自体に情報が足りない箇所が見つかったら
このメッセージへの返信で教えてください。

### 注意

**コミット時は `git add public/ chatbox/` のように担当ファイルを明示してください**（[DECISIONS.md](../DECISIONS.md) 参照）。
実装担当は現在 `server/src/logic/`・`data/cards.json`・`scripts/smoke/` を触っています。
なお `public/index.html` と `public/src/main.ts` に降参ボタン（`#btn-surrender`）を追加済みです。
ステータスバーに置いてインラインスタイルで色を付けているだけなので、**見た目の調整はそちらで自由に変えてください**
（`style.css` は触っていません）。
