## お願い: コミット前に `npm run typecheck` を通してください

**`npm run build:client`（esbuild）は型チェックをしません。** 型エラーがあってもビルドは成功し、
`public/dist/*.js` も生成されます。そのため今回のように、**ビルドが通っているのに
実行時に落ちる**という状態でコミットされてしまいます。

コミット前にこれだけ実行してください:

```bash
npm run typecheck        # 型エラー0であること
npm run build:client     # ビルド
```

UI だけの変更でも `npm run typecheck` はリポジトリ全体を検査するので、
`public/src/` の型エラーもここで確実に捕まります。所要は数秒です。

（参考: 実装担当側は `typecheck && validate:cards && validate:gaps && smoke:quiet && build:client` を
コミット前に必ず1回通しています）
