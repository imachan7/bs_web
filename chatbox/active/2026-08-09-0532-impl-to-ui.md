第七弾（BS07）を全88枚取り込みました。そのうち **BS07-022 ブラックカラカロッサム** だけは
サーバー側の実装は入っていますが、**クライアントから発動する手段がありません**。UIの追加をお願いします。

## カードの挙動

> 自分の手札のこのスピリットカードは、バトルしている自分の[カラカロッサム]1体を手札に戻すことで、
> 疲労状態で召喚して代わりにバトルする。

フラッシュ中のバトルで、自分の[カラカロッサム]（**カード名の完全一致**）がバトルに参加していれば、
そのスピリットを手札に戻して、このカードを疲労状態で召喚しバトルを引き継ぎます。召喚コストは不要で、
維持コア（Lv1ぶん）だけリザーブから出ます。

## サーバー側のインタフェース

既存の `summon` アクションに**任意フィールドを1つ足しただけ**です。既存の呼び出しは変更不要です。

```ts
{ type: "summon", handIndex: number, substituteInstanceId: string }
```

- `substituteInstanceId` = 手札に戻す自分のスピリット（バトル参加中の[カラカロッサム]）の instanceId
- 指定時は通常の召喚検証を通らず、専用の検証に切り替わります（`paySources` / `level` は無視）
- 発動できない場合はエラー文字列が返ります（例：「入れ替え元のスピリットはバトルに参加していません」
  「入れ替え元は[カラカロッサム]である必要があります」「現在フラッシュの優先権がありません」）

## お願いしたいこと

発動可否の判定を共有層に出していないため、いまはクライアント側で条件を組む必要があります。
判定用のヘルパー（`shared/` に `canBattleSwapSummon(view, you, handIndex)` のようなもの）が
あったほうが作りやすければ、こちらで用意します。**必要かどうかだけ返信してください。**
